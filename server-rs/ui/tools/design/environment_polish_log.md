# 地图/环境/道具精细化日志（environment polish）

改动仅限：
- `ui/js/world2d.js`（2D 俯视地图）
- `ui/js/zone3d.js`（3D 战斗副本）

未改动 `client.js` / `index.html` / Rust / assets；未引入任何外部库；对外方法
（`window.World2D` / `window.Zone3D`）签名与 `. .`/`#`/`I`/`P` 地格语义、碰撞判定一概不变。
全部新增为离屏烘焙或程序化低模，性能友好（装饰/材质烘焙进 tile 缓存，逐帧零计算）。

## 地板材质（world2d.js `buildTileCache` + `floorTexSrc`）
- 取代原「统一金属地板」，新增 **6 种材质变体**（每种带确定性噪点 + 接缝 + 磨损划痕）：
  1. 金属板（青灰钢板 + 铆钉 + 锈斑 + 划痕）
  2. 石板（灰色岩板 + 规则板缝 + 苔点）
  3. 木地板（深棕木板 + 木纹 + 钉眼 + 横向拼缝 + 磨痕）
  4. 沙地（土黄细沙 + 砂粒 + 风速波纹）
  5. 水面（深蓝水面 + 波纹高光 + 湿润反光）
  6. 苔藓地（暗绿湿苔 + 苔斑 + 细草叶）
- 由 `worldSeed`（从 `world.name + floor_name` 派生的稳定 FNV hash）+ 坐标 hash 确定性分桶，
  金属/石板最密、木/苔藓次之、沙/水稀疏点缀，分布稳定无逐帧抖动。
- 每种材质统一叠加「左上受光 + AO 角遮 + 底部内侧投影 + 高光线」立体层（`shadeFloor`）。
- `I`（设备）仍走专属暗底格（缓存格 7），`. `地板按材质分桶。

## 墙体细节（world2d.js 缓存格 6 + `drawWall`）
- 砖缝交错（两排横缝 + 交错竖缝）、砖面噪点斑驳、苔藓/污渍斑（呼应苔藓地）。
- 底部阴影渐变（墙脚压暗，与地板衔接更立体）；顶部受光边 + 顶沿高光（方块顶 rim）。
- `drawWall` 主立面由缓存格 6（旧格 3 迁移）取砖墙纹理，右暗侧 + 底部墙脚暗影逻辑不变。

## 环境装饰物（world2d.js 缓存第 1 行 + `floorDeco`）
- 离屏烘焙 **7 类环境细节精灵**：血渍 / 裂痕 / 碎石 / 植被杂草 / 水渍小洼 / 光斑 / 灰尘油污。
- 在 `.`地板格上按坐标 hash + 世界种子确定性点缀（总密度 ~22%，光斑偏稀疏、碎石/灰尘偏密），
  `drawImage` 叠到地板顶面，逐帧只付几次 draw，零遍历/零计算成本；未探索格不点饰。
- 让地图「活」起来（血渍/裂缝暗示战斗痕迹，植被/水渍呼应不同地板材质）。

## 道具精细表现（world2d.js 第 2 行图标 + `drawItemIcon` + 敌人/NPC 地面指示）
- 调查点/道具由「纯 ? 徽章 + 文字」升级为 **图标精灵** Canvas 绘制（离屏烘焙）：
  血瓶 / 钥匙 / 石碑 / 火把 / 卷轴 / 草药 / 水晶，按名称关键字归类（`itemIconIdx`），
  未命中按名称 hash 稳定给一个图标；图标下方仍保留名称小字可读性。
- 敌人脚下新增**地面指示圈 + 红光**（脉动红同心弧，随时间旋转），NPC 脚下新增**友好蓝白环**
  （与敌人红环区分）——都只画在已探索格，定位更清晰。

## 环境氛围（world2d.js `draw` 末尾）
- **角落暗角 vignette**：四角软径向暗罩 + 顶部微暗渐变收拢视野（固定几笔渐变绘制）。
- **尘埃/光斑粒子**：固定 ~26 粒屏幕空间缓慢飘浮（上浮回环），恒定开销、帧率友好。
- 均可选、可随地图任意配合，不影响判定。

## 3D 投掷物 + 命中爆炸（zone3d.js `throwFx` / `updateThrowables` / `isThrownWeapon`）
- 前端 `onAction` 只有 move/attack/dodge（当前契约无独立投掷 action），故采用视觉补偿：
  仍走 `onAction("attack",0)`，当 `curWeaponId` 命中投掷类（圣水/燃烧弹/投掷物/手雷/油瓶/飞刀等，
  `isThrownWeapon` 正则）时，攻击特效改为 **3D 投掷物飞行**。
- 小球体（圣水=圣蓝、燃烧弹=橙红，自带 emissive + additive 光晕拖尾）沿二次贝塞尔抛物线飞向敌人，
  命中（到点）后：**爆散方块粒子（18 片） + 地面爆炸光斑 + 冲击扩散圆环**；全程用 `blood` 粒子
  系统逐帧推进（`updateThrowables`），`resetPlayer`/`dispose` 清理。
- 命中判定/伤害仍在 Rust 侧，纯视觉。

## 战斗场地边缘 · 程序化低模装饰（zone3d.js `buildProps` 扩展）
- 在战斗区**边缘 1.5~2.8m 带状区**确定性散布 16 簇杂物，每簇 2~5 件，共 8 类：
  碎石堆 / 骸骨+骷髅 / 短管残段 / 散落小箱 / 沙袋堆 / 断墙残段 / 大型暗色混凝土块 / 散落砖块。
- 全用 BoxGeometry/CapsuleGeometry/CylinderGeometry 低模 + `castShadow/receiveShadow`，
  姿态确定性随机（seed 恒定、不抖）。另加 4 处干涸血迹/油渍地面贴片。
- 场中战斗区保持整洁（不失走位空间），氛围全集中在边带。
