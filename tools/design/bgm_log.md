# BGM 合成记录（bgm_log.md）

合成时间：2026-08-27
脚本：`tools/gen_bgm.py`（纯 Python `wave + math + struct` 手写采样，无 numpy）
参数：16-bit 双声道 wav @ 22050 Hz，首尾相位衔接可无缝循环
部署路径：`server-rs/ui/assets/audio/bgm_*.wav`

---

## 1. bgm_nexus.wav — 主神空间（空灵宏大）
- 时长：40.0 s（355,940 frames × 双声道 = 3,528,044 字节）
- 合成方式：
  - C 和弦垫（基频+泛音）：110 / 165 / 220 Hz 三个长音 sine 叠加（对应 C2/G2/C3 泛音关系）。
  - 缓慢音量 LFO：`0.6 + 0.4·sin(2πt/40)`，周期恰等于整段时长，保证首尾 LFO 相位衔接。
  - 高频谐波层 sparkle：330 / 440 / 660 Hz 弱音量点缀，营造空灵空间感。
  - 偶发钟鸣：每 10 s 触发一次指数衰减（`exp(-3t)`）的高频泛音组合（880 / 1760 / 2640 Hz）。

## 2. bgm_horror_loop.wav — 恐怖副本通用（悬疑恐怖）
- 时长：32.0 s（282,244 字节）
- 合成方式：
  - 低沉持续低音：60 + 66 Hz 两个 sine 叠加，形成 6 Hz 差拍（不安抖动）。
  - LFO 颤音：3 s 周期振幅起伏的 110 Hz；叠加 109 Hz 产生 1 Hz 差拍滑移。
  - 间歇不和谐高音：每 6 s 触发一次 `110 + 117 Hz`（7 Hz 差拍，增四度不和谐感），指数衰减。
  - 心跳式脉冲：每 1.6 s 触发两连跳（`exp(-20t)` 底音 64 Hz，模拟 ~75 bpm 心跳）。
  - 极低频质感：25 Hz 加慢速相位抖动。

## 3. bgm_battle.wav — 战斗（急促鼓点 + 紧张爬音）
- 时长：24.0 s（2,116,844 字节）
- 合成方式：
  - 急促鼓点：132 bpm（beat≈0.4545 s），每个 1/4 拍一个短促低频底鼓脉冲（`exp(-55t)`，75 Hz）。
  - 踩镲感：奇数拍（2、3 拍）短促 7000 Hz 高频脉冲。
  - 快速爬音：半音阶上行（4 步 `[0,2,3,5]` 半音往复，基于 220 Hz A 音），频率随时间上行制造紧张感；逐小节换目标音成 4 小节闭环，可无缝 loop。
  - 低音律动：55 Hz 持续低音打底。

## 备注
- 全部用周期性/整数关系频率与整段落时长，使首尾相位自然衔接，可无缝循环播放。
- 未改动任何 `.rs` 文件，BGM 播放接线留待后续实现。
