## 交叉验证与总判定

- **三张图(A 原始 / B 抠图 / C 透明预览)由 ox-alpha 独立判定,结论完全一致:**
  下半身(膝盖以下小腿与双脚)**全部缺失/被画面裁切**,无法通过简单边缘修复找回(素材本身未渲染脚掌);且人物边缘均为「生硬宽白蒙版」(约 10–25px 发泡白框)而非细 rim 光,属另一项明显缺陷(B 抠图透明区还有游离白块)。

- **与父代理像素统计冲突的说明:** 父代理报告 y600-1023 有腿脚实心像素。ox-alpha 三视角仲裁均认为这些像素是「被白描边蒙版包裹、且在画布底边截断的小腿/大腿残段」,脚掌(脚趾、脚掌向下)并无真实呈现。即便将宽白框计数在内,与「完整双脚在框内」的验收标准不符。

- **与另一视觉模型判定一致:** 与「下半身缺失需重生成」的判断互相印证。

- **总判定:需重生成 —— 该素材不可作为游戏主角 3D 精灵发布。**
  - 唯一否决性理由:下半身(腿/脚)不完整,脚掌缺失——这不满足全身精灵的硬性要求;
  - 附加问题:宽白蒙版式 rim 光 + 抠图白块/镂空,会使 3D 应用下的轮廓与 alpha 蒙版明显失真。

**重生成建议:**
1. prompt 明确 full-body framing、head-to-toe margin(头顶/脚底留空),禁用任何 sticker/die-cut/white border/cutout 类指令;
2. rim light 用 subtle/sharp thin cyan-white edge highlight,而非环绕式白描边;
3. 细化 hands/feet(脚趾、脚掌朝下、鞋面),确保双脚完整在画面内;
4. 抠图/去背保证 alpha 无白块、腿/脚区域无 punch-through。
