# 体素战斗人头部比例精益日志（头加大 / MC 大头观感）

日期：本会话
文件：`server-rs/ui/js/zone3d.js`（渲染层）
范围：仅改 `buildVoxelEnemy` / `buildVoxelPlayer` 的**头部 BoxGeometry**；躯干/四肢未动、VOXEL 开关/fallback/交互契约未动。

## 背景
GLM 对比判定：战斗体素人已达 MC 比例（23.2/25）。唯一可精益点为「D2 比例」4 分——头约 1/3 身高，未达 MC 更高大头的观感。本次仅加大头部，强化大头感知。

## 改动明细（旧 → 新）

### buildVoxelEnemy（L193）
- 旧：`box(0.5, 0.5, 0.5, ... , 0, 2.0, 0)`
- 新：`box(0.6, 0.6, 0.6, ... , 0, 2.05, 0)`

### buildVoxelPlayer（L219）

## 自洽校验（头 vs 躯干，二者同构）
- 头：中心 y=2.05，高 0.6 → 底 1.75 / 顶 2.35
- 躯干：中心 y=1.15，高 1.1 → 顶 1.70
- 头底(1.75) 紧贴躯干顶(1.70) 上方 0.05 → 头下压贴肩无悬浮缝；头加大后仍坐于肩上。

## 头占比（近似，scale 均乘 1.15 抵消）
- 头边长 0.5→0.6（+20%），头高占整个体素人高度比例提升，更接近 MC「大头感」。
