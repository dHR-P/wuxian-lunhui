## 0. 定位与铁律

### 0.1 基因锁在整个力量体系中的地位

基因锁是《无限恐怖》**最核心、贯穿始终**的力量路线：它是「人本身的潜能」，被主神/濒死激活，随阶位攀升把人从小卒抬到圣位门槛。在 Z 宇宙箱庭里，基因锁是**主角成长线的筋骨**，血统是「锦上添花的异类强化」，修真是「另一条平行天道」，科技是「外物」。三条/四条线**可以叠加**，但基因锁提供的是**「以伤换伤、越挫越勇、贴近死亡时最强」**的独特节奏——所有数值与机制都围绕「濒死→觉醒」这个母题展开。

### 0.2 四条铁律（贯穿全案，与 combat_system_design §0.2 / skills_system_design §1.3 对齐）

1. **数据驱动优先**：`gene_stage: u8(0-4)` 为主神/觉醒的权威字段；战斗结算查 `GENE_STAGES` 静态表；衍生能力查 `SKILLS` 表（gene 系并入统一技能表，非新 if 链）。
2. **绝不动现有 FightCfg/FIGHTS/血统字段语义**；敌人、技能、兑换全部走旁附静态表 + `Route::Dyn`/`fight_actions` 追加通道。
3. **一切新持久字段带 `#[serde(default)]` + 迁移管线幂等**；旧档天然可读。
4. **零回归**：未开启基因锁/未购技能时，动作列表与数值与现状完全一致；新逻辑只在 `gene_stage>0` 或持有技能时命中。

### 0.3 与现有字段的兼容（关键，承接 combat_system_design §0.1/§1.1）

| 字段 | 语义 | 兼容规则 |
|---|---|---|
| `gene_lock: bool`（现有） | 一阶布尔视图 | 保留；定义为 `gene_stage>=1`，兼容层维护/读取 |
| `gene_stage: u8`（新增，权威） | 0=未开，1~4=阶 | 兑换/觉醒统一走 `set_gene_stage(st,n)`：写 `gene_stage=n` 且 `gene_lock=(n>=1)` |
| 读当前阶 | helper `gene_stage_of(st)->u8` | `max(st.gene_stage, if st.gene_lock {1} else {0})`（engine 与 scenes 都走它） |
| 旧档迁移 | `migrate_save` | `gene_lock==true && gene_stage==0` → `gene_stage=1`；幂等（`gene_stage>=1` 跳过）；`save_version` 递增到 v3 |
| `ex_bought_gene` flag（现有） | 一阶兑换记号 | 保留，仅作展示；权威读 `gene_stage_of` |

> **落地提示**：所有「当前阶 / 是否已达某阶」判定统一用 `gene_stage_of(st)`；禁止在 engine/scenes 里再直接读 `st.gene_lock` 或 `st.gene_stage` 原始字段（除 helper 本身与 set/migrate 处），保证两条数据源一致。

### 1.1 一阶 · 战斗本能（人类·生死一线）

| 维度 | 内容 |
|---|---|
| **阶名** | **战斗本能**——「人体潜藏的善待生灵的原初警报被撕裂：死亡在耳边说话，身体抢在脑子前应答。」自创名义下取「本能·猎环」亦可。 |
| **解锁条件** | ① 濒死觉醒：战斗中 `hp<=30% 且 san>=20` → 觉醒判定（现有 licker 觉醒的通用化，见 §2.3）；② 主神兑换「基因锁·一阶·自主开启权」2000 点 + **D 级支线**（index §四：咒怨产出 D 级）。（现有行为原样兼容） |
| **主动特性（非纯被动）** | **子弹时间式反应**：战斗中不再只是闪避概率提升，而是特定回合可进入「直觉回放」——命中判定前对未来 1 回合的伤势无伤化闪避一次（建议触发点：濒死觉醒当回合免费送一次「极限闪避」）。感受是「时间变慢、血在倒流、每一道刀光都能看清轨迹」。 |

| **标志性衍生技能** | 战斗直觉（被动）、极限闪避（主动）、猎手凝视（主动·二阶前置）。 |
| **副作用** | 觉醒后 `san-`（建议 -8）；身体虚脱——觉醒后当回合无「守卫/allout」选项（建议值，可调；不强制）。 |

### 2.5 技能系汇总统计

- **基因锁系技能共 16 条**：一阶 4、二阶 4、三阶 4、四阶 5（含被动 1）。
- **kind**：主动 11 条 / 被动 5 条（instinct 战斗直觉、regen 再生、apex 规则承载等）。
- **need_stage 分布**：1 阶 4 条、2 阶 4 条、3 阶 4 条、4 阶 5 条。
- **消耗**：qi 为主（约 10 条），无消耗（per_fight 限 1）4 条，纯被动 5 条。与技能系统技能池（33 条）**合并后共 49 条**，需在兑换页分页处理（见 §4）。
- **克制/联动**：精神冲击对无精神抗性 debuff（§3.4）、空间折叠穿盾、规则领域范围 buff，均读现有 BATTLE_MODS/shi 盾体系，非新机制。

## §3 基因锁与其他体系交互

### 3.1 基因锁 vs 修真境界（两条线叠加规则）

| 维度 | 规则 |
|---|---|
| **叠加方式** | 两条线**独立平行、可叠加**：基因锁（血肉潜能）+ 修真（qi/真气·问心剑等，见 combat_system_design §1.3 与 skills_system_design §A 武道系）。二者数值**直接相加**，不互相排斥。 |
| **数值上限钳制（关键）** | **合力钳制**：`基因锁生效数值 + 修真加成` 的上限受「阶位合力天花板」约束——建议 `合力上限 ≈ 基因锁当前阶的期望档`（即四阶+高阶修真也不会无脑爆炸）。伪签名：`apply_total_atk(st) = min(gene_atk + wushu_atk, gene_expected_atk(stage) * 1.6)`（建议值·可调）。这承接 index §二 洪荒历「可控战力上限约四阶初中级」。 |
| **触发时机差异** | 基因锁靠濒死/危机（被动濒临档），修真靠 qi 资源（主动绝学）——二者天然互补：低 san/濒死时基因锁强，满 qi 时修真爆发。 |
| **血统叠加** | 血统被动（atk/减伤）与基因锁、修真**三方叠加**，但**外部被动总量**（血统+技能被动）受同一合力钳制约束，避免 40+ FightCfg 数值基线被稀释（对齐 skills_system_design §6.3.6）。 |

### 3.2 基因锁 vs 血统（血统是否受基因锁阶放大）

| 设计决策 | 内容 |
|---|---|
| **血统是否被基因锁放大** | **是，但分两类**：①**血统主动技能**（如 `sk_vamp_frenzy` 血之狂潮）的伤害受基因锁阶「濒死濒临档」加成（统一走 gene_atk 查表），即高阶基因锁让血统招式更致命；②**血统被动数值**（吸血鬼吸血/减伤）不直接×基因锁阶倍率，而是与基因锁被动**同列相加**并受 §3.1 合力钳制。 |
| **血统是否反向限制基因锁** | 建议**不禁**：血统（尤其非人血统如吸血鬼/祖巫）与基因锁兼容，仅对「玄门血统 vs 圣光」做剧情互斥（若实现走 `bloodline` 单值已有的互斥，无新字段）。 |
| **need_bloodline 技能** | 沿用 skills_system_design §1.2：血统被动提供数值，其专属技能提供主动爆发；`need_stage` 仅在少数血统技能上作为增强前置（如高阶血统招要求三四阶）。 |

### 3.3 基因锁 vs 科技/护盾（tech_shield）

- **合力钳制**把科技护盾的减伤纳入总减损，与基因锁减伤叠加但受上限约束。
- **空间折叠·初级**可穿透 `tech_shield` 与敌 `armor`（`ignore_armor`），是对抗高盾玩家的破防手段，也自然克制「科技侧防御流」。

### 3.4 基因锁三阶精神攻击对「无精神抗性敌」的 debuff（BATTLE_MODS 联动）

- **判定来源**：敌人是否有精神抗性，读 **BATTLE_MODS**（combat_system_design §2.1）新增一位 `aura_resist`/`mental_immune`（或复用 `san_resist` 概念）：默认无精神玩家的敌（多数 BOSS/兽类/机械）**无精神抗性**；带「无脊椎/死物/机械」标签（如量子机械壳 armor、酸血异形）可视作无精神通道但建议标 `mental_weak` 白名单。
- **效果**：精神冲击命中无精神抗性敌 → 附加 **意志溃散**：闪避 -0.15、持续 2 回合、并有概率（建议 30%）令其下回合 `no_dodge`（进 §3.1 stri ty）。对精神强敌（幽魂系/圣职者）无效。
- **落地**：数据层放在 `SKILLS.effect=DebuffEnemy`，触发读 `battle_mods(id)`，零侵入 FightCfg。

### 3.5 基因锁解锁的 sp_grade 评级门槛联动（承接 combat_system_design §1.1/§3）

- 基因锁各阶需对应支线评级：**一阶 D → 二阶 B → 三阶 A → 四阶 A(顶)**（建议值·可调）。
- 与副本经济闭环：咒怨 D（解锁一阶）→ 异形 C / 末世 C / 量子 D~C → 摩瑞亚 B（解锁二阶）→ 曙光 A（解锁三阶）→ 双 A / 高难位（四阶）。
- 兑换显示沿用 `cond_show_*` + `has_grade_or(st, need)`（combat_system_design §3 helper）；未达标展示价+评级、禁用购买。
- **濒死觉醒路径豁免评级**：濒死觉醒不要求 sp_grade——这是「有实力则越阶自发」的逃生通道，也是玩家无支线时的成长途径（见 §2.3）。

## §4 主神兑换基因锁页

> 承接 combat_system_design §3 / skills_system_design §5 的 `Route::Dyn + has_grade_or + cond_show_* + text_exchange/exchange_name` 模式。

### 4.1 兑换条目表（价格+评级门槛+濒死替代路径，数值建议值·可调）

| 条目 | 价格(点) | sp_grade 门槛 | 写状态 | 濒死觉醒替代路径 | 备注 |
|---|---|---|---|---|---|
| 基因锁·一阶·自主开启权 | 2000 | D | `set_gene_stage(st,1)` | 战斗中 hp≤30% 且 san≥20 觉醒（§2.3） | 现有，规则归一 gene_stage |
| 基因锁·二阶·入微 | 6000 | B | `set_gene_stage(st,2)` | 需已一阶 + 二次濒死 hp≤25% | 摩瑞亚 B 支线位 |
| 基因锁·三阶·禁忌 | 12000 | A | `set_gene_stage(st,3)` | 需已二阶 + 三次濒死 hp≤20% | 曙光 A 位 |
| 基因锁·四阶·顿悟 | 22000 | A(顶) | `set_gene_stage(st,4)` | 需已三阶 + 四次濒死 hp≤15%（极难自发） | 圣位下探，副本可控上限 |

> 各条目路由伪签名：
> ```rust
> fn route_buy_gene_stage(n: u8) -> impl Fn(&mut GameState) -> String {
>     move |st| {
>         let cfg = gene_stage_cfg_for(st, n).expect("stage");
>         if gene_stage_of(st) >= n { return "s_nexus_gene_already".into(); } // 已达
>         if st.points < EXCHANGE_GENE_COST[n] { return "s_nexus_exchange_fail".into(); }
>         if !has_grade_or(st, cfg.sp_grade) { return "s_nexus_gene_grade_fail".into(); } // 评级不足
>         st.points -= EXCHANGE_GENE_COST[n];
>         set_gene_stage(st, n);
>         "s_nexus_exchange_done".into()
>     }
> }
> ```
> **展示原则**：未达标条目在兑换目录可见（价+评级），购买时 route 校验 `has_grade_or` 返回 `s_nexus_gene_grade_fail`（文案「支线评级不足——濒死亦可觉醒，惊险才配得上力量」）。已购基因阶不计入可隐藏，但同阶内仅有一次性条目（无重复买）。

### 4.2 cond_show_* 可见性

- **一阶兑换**：`!st.gene_lock`（未开才显示）——沿用现 `cond_show_gene`，语义 = 未达一阶。
- **二三阶兑换**：`gene_stage_of(st)==前序阶`（逐级可显示下一阶）；`cond_show_ex_bought` 之类沿用。
- **濒死觉醒与兑换共存**：若已靠濒死先达某阶，兑换页该阶显示「你已凭借血与濒死觉醒此阶」文案（`text_exchange` 分支），不做重复购买。

### 4.3 濒死觉醒在副本内的触发演出（engine 注入点）

- **通用觉醒判定**（扩展现有 licker 觉醒逻辑为通用，见 §2.3）：`fight_turn` 在「玩家受击后 / 行动前」检查 `hp<=阈值 && san>=最低 && gene_stage_of < n`，若满足且 `晋级表`允许 → 触发一次觉醒：
  - 新增临时 flag `gene_awaken_n`（场次级），一次战斗只升一次；
  - 演出：战斗文本滚出一段濒死内心独白（自创，「血在倒数，那道锁……断了」）+ OverlayDef/card 演出；
  - 写入 `set_gene_stage(st, n)` + `san -= awakening_cost_san`（副作用）；
  - 副本地图级（非战斗探案）不下发濒死判定，只在战斗内生效（保持引擎最小改动）。

## §6 兼容红线清单

1. **`gene_stage: u8` 带 `#[serde(default)]`**（最高红线）；`GameState::new` 缺省 0；`gene_lock` 布尔视图保留并由兼容层维护。

9. **回归金标准**：playthrough / migrate_save / nexus_exchange / zhouyuan / yiying / moshi / moruiya / jiguancheng / tianshe / yinse 全量不得红；新功能以新增测试覆盖，不改旧断言硬数值。
