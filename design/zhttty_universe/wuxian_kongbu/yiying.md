## 0. 一句话概述

- **主题**：太空惊悚 × 战术猎杀 × 孵化恐怖；任务世界规则＝失控星际飞船上存活至主线目标达成。
- **一句话钩子**：「这艘船上的每一个暗角，都可能正在孵化。」
- **目标**：① 关闭船载 AI「Father」主控 → ② 引爆飞船反应堆 → ③ 活到撤离（登上贝蒂号）→ 回主神空间结算。
- **主线（主神发布）**：「在奥瑞迦号失控前达成三项主线目标并生还，奖励 400 点。提示：不要碰那些卵。」

## 1. 设定依据（源自原作）

- 《异形4：复活》（1997，让-皮埃尔·热内）中，主角一行登上太空军研究船「奥瑞迦（Auriga）」：船长艾尔金、佣兵约翰纳、轮椅机械师弗里茨、军人克里斯蒂、造人者原型「考尔（Call）」等八人小队，与瑞普利 8 号克隆体共同对抗船上的异形实验体与"父(混合)"（"Father"）船载系统——**封闭飞船环境 + AI 系统 + 反应堆引爆撤离**是本副本主线结构的直接出处。
- 系列核心设定（1979 版异形确立）：**抱脸虫**（Facehugger）将卵送入人体胸腔，**破胸体**（Chestburster）破胸而出，数小时成长为成体异形士兵；异形**酸血**可蚀穿船体金属与人体；成体以潜行、爬行（通风管）、突袭方式猎杀船员。原著中雇佣兵小队正是被异形在通风管与暗角逐一分杀（待补链接：百度百科「异形（外星生物）」词条 / 贴吧「异形吧」设定讨论帖）。
- 《无限恐怖》原著第二章任务世界即「异形4」：郑吒队在该世界初遇异形族群——异形卵、破胸体、速度快体型大的异形士兵，资深者的服从/背叛与新人死亡率在本作中也有对应设计（待补链接：起点《无限恐怖》第二章正文章节页）。
- 前作对应：现有《无限轮回·第一章 生化蜂巢》的「红后 AI→冷库→舔食者 BOSS」节奏，在本副本升级为「Father AI→孵化室→异形皇后」并上浮 30% 数值。

## 2. 主题与氛围

- **美术色调**：
  - 主色：冷金属暗蓝灰（船内 #1B2430 / 管道 #2E3B4E），应急灯红色（#FF3B30）与警示闪烁。
  - 孵化室/卵区：生物质绿黏液（#C6E76B 荧光绿）与半透膜卵壁；皇后巢穴：骨白 + 暗血红（#4A0E0E）的"胚胎教堂"。
  - 光语言：正常照明白 → 断电后的红外静默暗 → 反物质反应堆的幽蓝辉光（终局段）。
- **音效关键词**：蒸汽嘶鸣、液压作动、金属风管爬擦声、卵壳开合黏声、低频心跳（皇后附近）、断电死寂（环境静音 2 秒）、Father 的冷冽播报（女声）、异形咆哮与酸血蚀穿嘶声。
- **情绪曲线**（四拍）：
  1. **无声断电**（寂静不安，压低信任感）→
  2. **第一具破尸**（惊骇教学，确立"会破胸"的世界规则）→
  3. **抱脸虫寄生**（恐慌蔓延，倒计时压迫，队友可能被"定时炸弹"）→
  4. **异形猎杀-追逃-终局歼灭**（压迫-宣泄：气闸一击、熔毁皇后、引爆撤离的余波）。

## 3. 地图结构

- **楼层数**：3 层（建议 2-4 层区间内取值）；每层 `MAP_W=40, MAP_H=26`，字符集：`#` 墙 `.` 地板 `P` 出生点 `I` 装饰（床/罐/桌/卵）/ `G` 传送门与电梯井 / `E` 敌人驻点（示意）/ `B` BOSS 区。

## 5. BOSS 设计：异形皇后（Alien Queen）

- **fight id**：`f_yiy_queen`；**HP 200 / dmg 16-24 / 奖励 450 点 + C 级支线剧情 + 科技道具**。
- **狂暴血量**：35%（HP≤70）→ `on_rage=产卵暴走`：每 2 回合召唤 1 只抱脸虫增援（复用 `f_yiy_facehugger` 数值）、酸血四溅（全场每回合 `Hurt(3)` 区域蚀伤）、尾刺范围攻击 dmg+2。
- **狂暴表现（rage_text 文案）**：「皇后发出撕裂空气的尖啸，腹囊蠕动膨胀——卵从体内滚落，卵苞自行打开，抱脸虫如潮水般涌向地板。」
- **终结技条件（二选一，均算作"战术击杀"）**：
  1. **管道过热熔毁（推荐路线，对应支线 flag `yiy_queen_plan`）**：战斗/剧情进入 `ZoneDef yiy_pipe`（C3 反应堆管道区）后，选项「把皇后引向冷却管道」—若此前已关停 Father（`yiy_father_off`），Father 的散热协议失效 → 触发「过热熔毁」环境终结：皇后被 3000°C 等离子蒸汽烧穿（不触发酸血落地）；奖励全额 450 点 + flag。若未关停 Father 且无 `yiy_pulse`，皇后在管道区会先灭团（诱导死亡档案「硫磺与蒸汽」）。
  2. **电磁束缚 + 重火力**：需道具 `yiy_em_restraint`（电磁束缚装置，L2 生物实验室宝箱掉落，`AddItem`）：战斗中选择「释放电磁束缚」→ 皇后瘫痪 1 回合（硬直窗口），其后 2 回合玩家输出 ×1.5（文案「电磁网箍住皇后的骨冠，电弧滋滋作响」）；硬杀仍要防酸血（`Hurt(4)` 结算）。
- **胜利掉落**：`Points(+450)`、`sp_grade=C`（C 级支线剧情，见 §8 兑换挂钩）、科技道具二选一（`AddItem`）：
  - `yiy_gauss_blueprint`「高斯手枪图纸」——主神空间可兑换「高斯手枪（Weapon 强化）」；
  - `yiy_acid_sample`「异形酸血样本」——主神空间可兑换「抗酸涂层护甲」/卖给兑换目录 200 点。
- **失败去向**：被皇后拖入巢穴（死亡档案标题**「巢穴的养分」**）→ 回主神空间**扣点复活**（异形复活价建议 600 点，详见 §8）。

## 10. 实现风险与建议

### 10.1 需要的新系统（相对现有引擎）

1. **支线剧情评级字段 `sp_grade`（D/C/B/A/S）**——研究文档 §5.3 明确建议；引擎目前只有 `points`，需在 `GameState` 增字段 + 结算卡展示 + 主神空间兑换门槛判定。**最高优先级**（本副本掉落 C 级支线，兑换闭环依赖它）。
2. **计时/幕数判定（寄生倒计时）**——引擎无回合计时器。最小改动方案：纯 DSL 落地（章节判定用 `cond` + 关键场景分支：`yiy_infected` 置真后，非 `yiy_cured` 时进入第 N 个调查/撤离场景即强制触发死亡分支）；可选增强：`ChoiceDef`/`SceneDef` 增 `deadline_moves` 或全局 `timer_flag` 字段。**推荐先纯 DSL，后补字段**。
3. **EnemyDef 巡逻路径与警戒预警文本**——现有 `EnemyDef{radius}` 是驻点徘徊；异形「通风管异响→现身」预警需在**触发战斗前**给玩家一段追猎文本。最小改动：给 `EnemyDef` 增可选 `path: [(x,y),...]` 与 `preface_text`（触发时先播文本再进 FIGHTS）；预览可先用 `PointDef` 预警文案模拟。
4. **酸血残留（`post_kill_acid`）**——击杀异形成体后下个行动受 3-5 蚀伤。最小改动：FightCfg 增可选 `post_kill` 效果字段（落地为 `Eff` 链：`Hurt(4)`+文案）；预览可用现有 `win` 分支静态结算。
5. **气闸鼓舞环境击杀（ZoneDef kind=env_kill）**——把异形引进气闸一键消灭、错位误伤队友。纯 DSL 可先落地（`ZoneDef yiy_airlock` + 选项分支：成功 `Points(80)+flag` / 失败 `Hurt(10)+San(-10)` + 误伤考尔）；通用化（战斗内分流）列为可选增强。

### 10.2 风险与对引擎的最小改动建议（不写 Rust，仅行为描述）

- **难度曲线**：蜂巢基线 +30% 会让「无脑正面战」层末 BOSS 前资源崩盘 → 必须给足**两条解（气闸/管道/电磁束缚+绕行）**，否则挫败感失控；建议数值先按表落地，QA 后按「首次通关率 ≥25%」微调 dmg 上限或奖励。
- **寄生死链**：寄生倒计时与「撤离限时」叠加可能造成连死挫败 → 倒计时只挂玩家自身且医疗舱必达（绕行最短路线），不要把倒计时挂在必死 NPC 上。
- **Father 双分支**：`yiy_father_off` 双路线（智慧/暴力）共 5 处门禁/终结技引用该 flag → 实现时统一在 `GateDef/GateDef.Dyn` 层判 flag，避免散落硬编码。
- **立绘成本**：4 张新立绘（士兵/哨兵/猎手/皇后）+ BOSS 大立绘是成本大头 → 阶段一先「舔食者小改」跑通全流程，阶段二再补新立绘替换引用（美术需求已列 §9.1）。
- **地图 ASCII 精度**：本文 ASCII 为示意稿（≤40×26），落地以 §3 各层「区域划分表」坐标为权威 → 主 agent 实现时按坐标表生成房型，用绝对坐标防越界。
- **酸血/环境伤害的 death_route**：所有 `Hurt` 需带 `death_route`（回落死亡档案），避免流程卡死在 0 HP。
