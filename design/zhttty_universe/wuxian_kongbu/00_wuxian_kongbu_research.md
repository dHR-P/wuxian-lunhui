## 1. 作品概述

- **类型地位**：中文网文「**无限流**」开山之作（起点中文网 2007 年连载，作者 zhttty/张恒），
  开创「主神空间+电影/恐怖片任务世界+点数兑换」范式，后续《无限未来》《无限曙光》等构成
  「无限宇宙」系列。本游戏即复刻其第一部的框架与名场面。
- **故事梗概**：普通人被主神（主神空间中央光球）随机选中，进入「恐怖片世界」执行主线任务。
  完成主线任务 → 主神传送回主神空间结算（奖励点数/支线剧情），可兑换血统、技能、装备；
  任务失败或在世界内死亡 → **真实死亡**（「主神不会复活新人」是开篇名台词）。
- **叙事与情绪基调**：真实化恐怖片世界中的生存挣扎、道德困境（救人 vs 自保）、队友情谊、
  以及「为了活下去什么都做得出来」的人性底色；后期揭示主神空间真相与神魔级对抗（本阶段
  游戏仅用前期框架，不涉及后期主线剧透）。
- **与本游戏的关系**：现有《无限轮回·第一章 生化蜂巢》即复刻其第一章「生化危机·蜂巢」；
  主神空间雏形（张杰 NPC、兑换目录、S/A/B/C/D 评级结算）与原著设定一一对应。

## 2. 核心设定与力量体系

### 2.1 主神空间（Main God Space）
- 结构：空旷广场 + 中央**光球（主神）** + 每人一间私人房间 + 通向任务世界的传送光柱。
- 职能：发布任务、发布主线/支线、发布兑换目录、复活/治疗/强化（后期开放）、队伍管理、
  进入下一场恐怖片的传送。
- 规则：任务中途不可主动退出（主线完成即被强制传送回主神空间）；兑换需「奖励点数
  + 支线剧情（D/C/B/A/S 等级）」双货币；可兑换血统/基因锁强化/技能/装备/道具/宠物等。
- 游戏对应：现有 `s_nexus` 主神空间雏形（半圆形广场 + 张杰 + 兑换目录）→ 需扩展为
  「主箱庭」：多 NPC、多传送门（每传送门一个任务世界）、复活/评价/兑换分区。

### 2.2 基因锁（Genetic Lock）
- 设定：人类基因中封存的力量，通过**濒死/极限危机**解封，解锁阶段越高战力越恐怖，
  是主角郑吒的核心成长线。
- 阶段（前期框架用 1~2 阶，后期为 3~4 阶与血肉升华）：
  - **一阶**：神经反射/力量/速度全面增幅，战斗本能释放；解锁后身体剧痛、虚脱（副作用）；
    体现为「以伤换伤、爆发输出」。
  - **二阶**：肌肉、内脏、骨骼局部可控（爆发力、抗打击提升）。
  - **三阶**：感知与直觉强化（预判、读心雏形）。
  - **四阶**：基因层面控制，细胞重组/局部异化（后期，本阶段不落地）。
- 游戏对应：生化蜂巢 BOSS 战已实现「HP<30% 且 SAN≥20 觉醒基因锁一阶（攻击×2.5、必定
  闪避一次）」；主神空间已有「基因锁第一阶段 2000 点 + D 支线」兑换项 → 新副本可做
  「二阶段基因锁」兑换或「战斗中二次觉醒」验证点。

### 2.3 血统（Bloodline）
- 设定：通过主神兑换获得非人血统，提供属性与特殊能力，分等级叠加（D→C→B→A→S）。
- 代表：**吸血鬼血统**（速度/恢复/吸血，怕银与阳光）、狼人血统、祖巫血脉（后期玄幻系）、
  天妖血统等。血统可激活「血统技能」，与基因锁叠加成为核心战力。
- 游戏对应：主神空间已有「初级吸血鬼血统 3000 点 + C 支线」→ 新副本应设计对应支线剧情
  产出（C/D 级支线），让兑换不落空。

### 2.4 兑换体系与支线剧情点数
- 奖励点数（Points）：杀敌、主线任务、支线任务、救人、BOSS 战获得；通用货币。
- 支线剧情（Side Quest Plot，D/C/B/A/S 级）：完成隐藏任务获得，**高等级兑换的门票**
  （血统、高级装备、基因锁二阶段均需 D/C 以上支线）。这是「必须打支线才配得上
  高级兑换」的经济闭环。
- 装备/道具：冷兵器（刀/剑/斧）、热兵器（沙漠之鹰、高斯枪械）、防具、消耗品（圣光弹、
  十字架、肾上腺素、解毒剂、符咒、回血药剂）、辅助道具（空间袋、探测器）。
- 能力：内功/魔法/念动力/专属技能均可兑换；同一能力按等级递增。
- 游戏对应：引擎已有 `points`/`Eff::Points`/`AddItem`/`Weapon`；**支线剧情（评级 D/C/B/A/S）
  目前引擎没有独立字段** —— 属建议新增系统（任务C 的 newSystems 关注点）。

### 2.5 任务世界规则（恐怖片世界）
- 入场：主神发「主线任务」（如：存活 X 天 / 达成某个目标），任务期间禁止退回，世界内
  敌人与环境真实化。
- 支线：隐藏任务/剧情人物线，达成后额外点数+支线剧情评级。
- 资深者/新人：资深轮回者负责讲解规则（张杰即引导者职能的原型）；新人死亡率极高。
- 回归：主线达成 → 主神光柱强制传送回主神空间 → 结算（点数/评级）→ 兑换 → 下一场。
- 队伍对抗（后期）：恶魔队/天神队跨队任务（本阶段不落地，仅预告用）。

## 4. 经典任务世界清单（原著出现，评估改编价值）

原著主线任务世界顺序（据社区公认整理，web 无法核实本轮）：生化危机 → 异形4（异形）
→ 咒怨 → 死神来了 → 木乃伊 → 星河战队 → 侏罗纪公园 → 魔戒（指环王）。
按改编价值与本引擎（40×26 网格箱庭 + 回合战斗 + 3D 立绘）评估如下：

### 4.1 生化危机·蜂巢（✅ 已实现）
- 代表性情节：地下列车入场、B餐厅丧尸教学战、激光通道名场面、红后、舔食者 BOSS。
- 已落地：4 层箱庭副本 + 舔食者基因锁觉醒终结 + 死亡档案系统。
- 结论：保留为「第一副本」，作为后续副本难度标尺（敌人 HP/奖励点数值基线见 ENGINE_CONTEXT §2.3）。

### 4.2 异形4／异形（改编价值：★★★★★）
- 代表性情节：太空船内异形破胸孵化、抱脸虫、异形捕猎小队、最终决战异形皇后。
- 改编价值：封闭飞船天然是网格箱庭；「孵化→猎杀」节奏适合回合制（先情报后战斗）；
  异形视觉辨识度极高，立绘冲击力强。
- 建议：3 层（船员区/实验室与巢穴/引擎区），BOSS 异形皇后（或异形母体）。

### 4.3 咒怨（改编价值：★★★★★，**本轮优先实现**）
- 代表性情节：佐伯家凶宅、伽椰子咒怨链、俊雄鬼童、二度死亡循环（被诅咒者必死）。
- 改编价值：纯心理恐怖+规则解密适合文字剧情 DSL；敌人少而精（怨灵），可把战斗做成
  「魂火/怨念条」机制；SAN 值系统（引擎已有）天然契合。
- 建议：3 层（宅邸一层/二层/阁楼与地下室），BOSS 伽椰子（怨念之源）。

### 4.4 死神来了（改编价值：★★★☆）
- 代表性情节：死神设计「意外死亡」连环杀、预感闪回、躲避死神的死亡名单。
- 改编价值：**无实体敌人**，核心是环境机关与「死亡预感」机制 —— 与引擎现有
  「机关/陷阱/flag」契合但需要新增「死亡征兆倒计时/危机预告」系统，战斗偏薄。
- 建议：作为中期「机关解谜型」差异化副本，3 层（机场/公路/住宅），BOSS 死神使者
  （可战斗化处理）或纯机关关（无 BOSS）。

### 4.5 木乃伊（改编价值：★★★★）
- 代表性情节：埃及考古、圣甲虫潮、祭司复活诅咒、沙漠地宫。
- 改编价值：解谜+宝藏+木乃伊怪物组合丰富；地宫天然多层箱庭；宝箱奖励体系好做。
- 建议：3 层（地宫入口/圣甲虫厅/祭司墓室），BOSS 大祭司伊莫顿（复生阶段）。

### 4.6 星河战队（改编价值：★★★）
- 代表性情节：虫族(脑虫/虫子海)军团作战、装甲步兵。
- 改编价值：大规模杂兵战适合后期高难度+群体战斗，但与现有「舔食者等精英战」风格
  差异大，美术成本高（需要大量虫族立绘）。
- 建议：后期扩展副本，3 层（登陆场/地洞/脑虫巢穴），BOSS 脑虫。

### 4.7 侏罗纪公园（改编价值：★★★）
- 代表性情节：恐龙失控、逃生、霸王龙/迅猛龙猎杀。
- 改编价值：开放式岛图+恐龙追击，氛围足；与现有封闭走廊副本差异化。
- 建议：后期扩展，2-3 层（园区/丛林/围栏区），BOSS 霸王龙。

### 4.8 魔戒／指环王 · 摩瑞亚矿坑（改编价值：★★★★★，本轮二选一入选）
- 代表性情节：护戒队穿越摩瑞亚矮人地下城 —— 无底阶梯、石厅、书库（「咚…咚…咚…」
  炎魔鼓声）、最终在石桥对抗**炎魔（Durin's Bane）**；另有水中监视者（湖中之妖）。
- 改编价值：**地下城探索与网格箱庭完美同构**（迷宫式多层矿坑）；敌人谱系完整
  （半兽人/魔怪/炎魔），BOSS 战史诗感强；道具（秘银甲、矮人宝库）契合掉落体系；
  难度可做到系列天花板。
- 建议：3 层（矮人故居/长书库与无底阶梯/卡扎督姆桥），BOSS 炎魔（狂暴=火焰形态）。

> **本轮二选一结论：选《魔戒·摩瑞亚矿坑》，放弃《死神来了》** —— 本引擎是
> 「战斗+探索」驱动，摩瑞亚敌人/BOSS/宝箱三大件全部契合且零新增核心系统；
> 死神来了需要「环境拟死」新系统且无战斗主力，成本/收益比不高，留作后续差异化候选。

## 5. 与现有生化副本及主神空间的联动建议

1. **难度标尺**：以生化蜂巢数值为基线，副本难度梯度建议
   咒怨（同难度/低一档，靠 SAN 加压）＜ 异形（上浮 30%）＜ 摩瑞亚（上浮 60%，系列天花板）。
2. **主神空间扩展为主箱庭**（建议本轮联动落地）：
   - 广场 NPC 三角：张杰（规则/剧情）、詹岚（下一副本情报预告）、楚轩（兑换顾问）。
   - 传送门区：每副本一个传送门（已通关可重复挑战刷分，未通关显示「？？？」+詹岚预告）。
   - 兑换目录扩充：新增「基因锁二阶」「支线剧情评级兑换门」（D 支线才能买中级血统等）。
3. **支线剧情（评级货币）系统**：当前引擎只有 `points`，建议新增 `sp_grade`（D/C/B/A/S）
   字段，由各副本支线 flag 达成解锁；咒怨做 D 级支线、异形做 C 级、摩瑞亚做 B 级，
   与主神空间兑换门槛挂钩 —— 驱动玩家回头刷低阶副本。
4. **死亡/复活闭环**：失败→回主神空间「扣点复活」（引擎已有设计意图），复活价格按副本
   难度递增；死亡档案（overlay deaths）每副本各 4-6 种，形成「死法收集」长线乐趣。
5. **立绘与声音复用**：普通丧尸/舔食者立绘已在蜂巢使用；新副本优先「复用+小改」，
   只对新核心怪（伽椰子、俊雄、异形、异形皇后、半兽人、炎魔）申请新立绘（美术需求清单
   写进各自副本文档第 9 节）。
6. **剧情钩子（原著向）**：张杰台词点出「下一场是《咒怨》」作为蜂巢结尾预告（现有 GAME_DESIGN
   已留《咒怨》预告位）；詹岚情报 NPC 补《异形》预告；摩瑞亚作为「B 级难度里程碑」预告，
   形成「生化→咒怨→异形→摩瑞亚」的引导式难度曲线。
