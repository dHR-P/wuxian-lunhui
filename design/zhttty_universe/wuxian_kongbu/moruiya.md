## 0. 一句话概述（主题/钩子/目标）

- **主题**：史诗地下城探索 + 远古矮人遗迹 + 逐层逼近深渊之火的绝望感。护戒/探索小队必须穿越摩瑞亚（卡扎督姆）——从西闸门一路下行，穿过柱厅、长书库与无底阶梯，最终在卡扎督姆桥直面苏醒的炎魔。
- **一句话钩子**：「摩瑞亚在黑暗里等着你们——深渊之下，有什么东西苏醒了。」
- **目标**：主线 = 从西门抵达东门（穿越摩瑞亚，击败炎魔·都灵的克星）；支线 = 寻找矮人王厅宝库中的「秘银」（可选，高奖励）。

## 1. 设定依据（源自原作具体情节）

- 代表作情节：《指环王：护戒使者》中护戒队经西门进入摩瑞亚（矮人地下城卡扎督姆）的完整段落——西闸门湖中监视者（Watcher in the Water）袭击、矮人故居与柱厅、长书库（马扎布尔书库）中巴林之墓与持续「咚…咚…咚…」的炎魔鼓声、无底阶梯、最终在卡扎督姆桥的断桥决战。
- 原作细节引用（依电影台词/原著记忆）：
  - 甘道夫在门外警告：「摩瑞亚——你们愿意的话可以叫它卡扎督姆……矮人们挖掘得太深、太贪婪（They delved too greedily and too deep），唤醒了‘都灵的克星’。」（「都灵的克星」Durin's Bane 即炎魔，为摩瑞亚塌陷的根源）
  - 长书库段落：巴林之墓的墓碑铭文与《马扎布尔之书》残页记载矮人远征队的覆灭；随后低沉的鼓声自深井传来，「咚…咚…咚…」，越来越近——半兽人大军与巨魔涌出。
  - 卡扎督姆桥决战：甘道夫独立桥中，断喝「You shall not pass!」，以法力击断石桥，炎魔坠入深渊——却在坠落的瞬间以烈焰长鞭缠住甘道夫，将其一同拖下（「甘道夫式牺牲」）。
  - 西闸门湖中监视者：护戒队刚进门即遭触手怪袭击，弗罗多被拖向水面，被解救后众人在门内眼睁睁看着巨门被触手封死——**后路断绝**，只能向黑暗深处前进。
- 社区参考来源：web_search 本会话不可用，链接待补（后续主 agent 可补：百度百科「指环王：护戒使者」词条、托尔金维基/灰袍甘道夫 Wiki「Moria / Balrog / Watcher in the Water」词条、IMDB 台词页 "You shall not pass"）。

## 2. 主题与氛围

- **美术色调**：黑曜石冷蓝（矿坑岩壁、幽暗湖水）为底，烛火/火把的暖琥珀色为点缀；深层转向暗红/橙红的「深渊之火」渐变（炎魔逼近时整个画面透出红光）。道具/机关用矮人符文微光（秘银银白）。
- **音效关键词**：石厅空旷回音（脚步、滴水）、远处低频鼓声「咚…咚…咚…」（随楼层递进越来越近、越来越响）、矮人机关齿轮/石门碾动、监视者出水声、炎魔火焰嘶鸣与深渊咆哮、断桥崩裂。
- **情绪曲线（五段式）**：
  1. 初入遗迹的**宏大惊叹**（西闸门柱厅，烛火摇曳）→
  2. 坍塌堵路的**紧张**（塌方绕行、后路被封）→
  3. 长书库鼓声的**压迫**（SAN 持续掉落，半兽人伏击）→
  4. 无底阶梯的**窒息**（坠落陷阱，一步踏空即死）→
  5. 石桥炎魔的**史诗终局**（断桥坠渊 / 甘道夫式牺牲双结局）。
- **SAN 联动基调**：黑暗=持续低量 SAN 流失（火把可缓解）；鼓声=SAN 阶段性骤降；炎魔=全场高温 SAN 光环（每回合）。

## 5. BOSS 设计：炎魔·都灵的克星（Durin's Bane）

- **HP**：270；**伤害区间**：18-26（普通形态）；**奖励点**：600。
- **狂暴血量**：HP ≤ 135（50%）——**火焰形态**：烈焰长鞭横扫（dmg 上限 +3，范围变为「全场」）、每回合全员 San(-6)（火焰形态）、全场高温环境 San(-3)/回合（进战斗即生效）。
- **狂暴表现**：立绘切换为火焰形态剪影（火焰更亮、身形轮廓抖动），场景背景透出橙红深渊之火；鼓声达到顶点后骤然消失（"The drums… have stopped."），随即炎魔自桥下升起。
- **终结技条件（双结局）**：
  - **A「断桥坠渊」**：战斗发生于桥中段 Zone（bridge_mid，(22,13) 半径内）且甘道夫存活 + 炎魔 HP<30%（<81）→ 选项「引它冲锋/斩断桥索」→ 环境终结：石桥断裂，炎魔坠入深渊（判胜，不走死亡档案）；甘道夫存活 → flag `bridge_broken`（结算 +200）。战利品：600 点 + B 级支线剧情 + 传说掉落。
  - **B「甘道夫式牺牲」**：任意阶段可选 → 甘道夫持杖断桥，与炎魔同坠深渊（判胜）→ flag `gandalf_sacrifice`（+300 点 + **B 级支线剧情**）；甘道夫「牺牲」（剧情牺牲，不计入队友死亡档案）。战利品同上，另获得特殊台词演出。
- **胜利掉落**：600 点 + B 级支线剧情（sp_grade=B）+ 传说掉落二选一（条件判定）：「精灵斗篷」防具 或 「秘银护甲图纸」；若已开宝库支线，精灵斗篷概率上调。
- **失败去向**：被炎魔拉入深渊 → 死亡档案「坠入卡扎督姆深渊」→ 全队回主神空间扣点复活（见 §8）。
- **BOSS 台词**：开场「You shall not pass!」（甘道夫）——炎魔以烈焰长鞭回应；狂暴后甘道夫：「深渊之火……它的名字是都灵的克星。」

## 8. 与主神空间衔接

- **入口传送门规则**：主神空间广场新增「摩瑞亚」传送门（第二副本位）。解锁条件：通关《生化·蜂巢》后由张杰台词解锁（"这次的世界，可不只是丧尸了。"）。进入消耗 0 点；进入即随机生成 flag 初始态（每次挑战重置支线 flag，可重复刷分）。
- **退出条件**：击败炎魔（断桥坠渊或甘道夫式牺牲任一结局）→ G6 东门开启 → 主神光柱强制传送回主神空间结算（沿用 compute_settlement）。任务中途不可主动退出（呼应原著「主线达成即强制传送」）。
- **失败惩罚（扣点复活）**：副本内死亡（任意死亡档案）或全灭 → 回主神空间结算页进入「复活区」：每人 600 点复活（副本首次死亡 400 点，按难度递增；生化蜂巢为 300 点基线）；点数不足 → 记为「欠债」，下一次进副本前优先偿还（点数可为负，用后续副本收益抵扣）。
- **本副本对兑换项的影响**：
  - 产出 **B 级支线剧情**（炎魔胜利/甘道夫牺牲）→ 解锁主神空间高阶兑换门槛：**基因锁二阶段（B 级支线）**、**秘银护甲（B 级）**、**精灵斗篷（C 级）** 入兑换目录。
  - 秘银块可折价 100 点；矮人战斧入武器架。
  - 难度里程碑达成 → 詹岚 NPC 预告下一副本《异形4》（与摩瑞亚同级天花板；"封闭的太空船，抱脸虫，还有……皇后。"）。
- **支线评级货币（sp_grade）联动**：本副本为「B 级支线」产出位（按研究文档规划：咒怨=D、异形=C、摩瑞亚=B，驱动玩家回头刷低阶副本凑齐兑换门槛）。

## 10. 实现风险与建议

### 10.1 需要的新系统（按风险排序，均给「最小改动」退路）

1. **火炬/黑暗视野光照系统**（新，中等风险）：地图装饰与 SAN 联动——黑暗区域（ZoneDef 新 kind `dark`）视野受限、遭遇概率上升；持火把者不能潜行（遭遇率反升于潜行场景）；火把熄灭 → SAN 流失与遭遇率叠加。
   - 最小改动退路：初版不引入网格光照，用「flag `torch_lit` + 文本描述 + Eff::San + 遭遇率系数」简化实现（状态字段 `light: bool` 即可），前端仅叠加一层暗色滤镜。
2. **支线剧情评级货币 sp_grade**（新，低风险）：state 增加 `sp_grade` 字段（D/C/B/A/S），结算时写入；主神空间兑换项加 `need_sp_grade` 门槛判断。
   - 最小改动：先落 `sp_grade` 字符串字段 + 兑换门槛判断，UI 展示评级徽章后续迭代。
3. **战斗内环境终结（断桥坠渊）**（新，中风险）：FightCfg 的 finisher 扩展 `env_zone` 条件（需当前站位 ZoneDef）+ 环境判胜分支（不写死亡档案）。
   - 最小改动：初版沿用现有 finisher 机制——桥段纯文本演出 + 直接判胜（不引入站位系统）。
4. **每回合持续 SAN 光环（炎魔高温）**（新，低风险）：FightCfg 增加可选 `per_turn_effects: Vec<Eff>`（每回合对全员生效）。
   - 最小改动：退化为「进入 BOSS 战一次性 San(-10) + 狂暴触发时再 San(-8)」。

### 10.2 已支持、无需新系统的机制（验证即可）

- 坠落陷阱：PointDef 调查 + Eff::Hurt(amount, death_route) → 死亡档案（无底阶梯三陷阱）。
- 门禁：GateDef need_item/need_flag（G1-G6 六门）。
- 单向传送门：PortalDef 物理单向（P1 矿车、P2 塌方）。
- SAN 数值与死亡档案：Eff::San / OverlayDef（死亡档案 6 种：watcher_drown 湖妖拖入水中、stair_fall 坠入无底阶梯、balrog_fall 坠入卡扎督姆深渊、flame_burn 烈焰焚身、dark_mob 黑暗中窒息、rubble_crush 被塌方掩埋）。
- 结算：compute_settlement 沿用（点数 + 存活队友×100 + 支线flag×200，S≥1600/A≥1300/B≥1000/C≥700）。

### 10.3 数据量清单（供主 agent 排期）

- FIGHTS 表新增 9 套：goblin_scout / goblin_pack / goblin_raider / drum_ambush / orc_captain / cave_troll / orc_guard / watcher / balrog。
