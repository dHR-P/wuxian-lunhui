## 0. 一句话概述

- **主题**：日式怨灵心理恐怖 + 诅咒规则解密。怨念不是怪物，而是「规则」——被盯上、被叠加、最终被拖入二重死。
- **一句话钩子**：「从你踏进佐伯家玄关的那一刻起，诅咒已经开始倒计时。」
- **目标**：在佐伯家凶宅内存活至次日清晨 6:00，并找出怨念源头（伽椰子之死的真相 / 日记 / 尸体），以解除诅咒或完成仪式封印离去。
- **主线任务文本（主神发布）**：「主线任务：在佐伯家宅邸内存活至清晨六点，并调查怨念之源。在任务完成前，禁止离开宅邸范围。失败代价：被咒入二重死。」

## 1. 设定依据

引用《咒怨》（日版 2002）原作细节（社区/百科来源链接待补，web 搜索本轮不可用；内容据电影实拍与设定集）：
1. **凶宅结构**：佐伯家是独栋和式老宅，玄关木台阶、客厅电视、二楼走廊尽头的壁橱与主卧、阁楼夹层藏尸处、地下储物间——「宅邸本身就是怨念的容器」，踏入者即被感染。
2. **伽椰子之死**：女主人伽椰子（Kayako）被丈夫刚雄（Takeo）在暴怒中杀害，尸体藏在阁楼天花板夹层里，被报纸与塑料布裹着；幼子俊雄（Toshio）被一同杀害（尸体被藏入壁橱/衣柜）。怨念化为「咒怨」——凡进入宅邸者皆被锁定，死亡如病毒般在人际链条上传染，被咒者会「死两次」（二重死）。
3. **怨念意象**：伽椰子以白裙黑发覆面、四肢着地爬行的姿态出现，喉咙发出「嘎——」的喉音；俊雄以苍白幼童形象伴随猫叫「喵——」出现，会主动引路（如把前来者引上二楼），引路究竟是救赎还是陷阱，是全片最大悬念。
4. **真相关键物**：伽椰子的**日记**（记录她对大学老师小林俊介无果的暗恋，是怨念的情感内核）与**婚礼照**（照片上门缝外的黑气）是理解怨念之源的钥匙。

> 《无限恐怖》原著中咒怨世界是郑吒队早期经典恐怖世界（社区公认序列第三场，位于生化危机之后），核心是鬼域类生存 + 心智 SAN 战；主线任务即为「在鬼宅内存活到天亮」，靠灵符/佛珠类道具与规则对抗（来源链接待补：起点《无限恐怖》正文第 20 余章咒怨卷、百度百科「无限恐怖 咒怨」词条）。

## 2. 主题与氛围

- **美术色调**：惨绿/灰蓝冷调为基底。玄关与走廊偏灰蓝（雨夜无月光），室内偏惨绿（老旧荧光灯、发霉墙纸）；阁楼昏黄（天窗漏雨光 + 旧报纸反光）；地下室近乎漆黑，仅在结界白线处有惨白微光，BOSS 战中黑发铺地后转「全黑 + 惨白高光」。
- **音效关键词**：连绵雨声（全层底噪）、木质老宅吱呀声、小孩拍球声（楼下传来却无人）、猫叫（俊雄）、喉咙「嘎——」喉音（伽椰子）、四肢爬行的「哒咔哒咔」、钥匙/门闩金属摩擦、倒计时般的钟摆声（凌晨 3 点后）。
- **情绪曲线**：日常渗入诡异（玄关、雨鞋、客厅电视雪花）→ 灵异事件叠加（壁纸鼓包、镜子延迟、拍球声）→ SAN 压力飙升（俊雄引路二选一、主卧床下、藏尸处）→ 真相揭示高潮（日记、婚礼照、尸体）→ 祭坛结界决战 → 救赎结局（伽椰子流泪消散、俊雄化白猫离去）或坏结局（被咒入二重死）。
- **SAN 设计定位**：本副本以 SAN 为「第二血条」。大量 PointDef 灵异事件触发 `hauu` 演出 + SAN 惩罚；SAN≤20 时镜头晃动、语音低语、强制遭遇概率上升（复用蜂巢低理智恶化）；SAN=0 触发即死档案「湿冷雨夜」。

## 8. 与主神空间衔接

## 10. 实现风险与建议

| 风险/需求 | 说明 | 对引擎的最小改动建议 |
|---|---|---|
| **诅咒标记叠层**（最依赖新逻辑） | BOSS 与主卧惩罚需要「标记叠加→强制遭遇/即死」计数链。引擎 `flags` 为布尔集合，无计数类型 | **方案 A（最小）**：预约连号 flag `zy_curse_1/2/3`，`cond` 逐级判定（实现现有 Eff/cond 即可支撑）；**方案 B（推荐）**：新增 `Eff::MarkCurse(n)` 与 `state.curse` 计数，`cond` 加 `Cursed(n)` 谓词，改动集中在 state.rs + defs.rs 两处 |
| **支线剧情评级 `sp_grade`** | 研究文档已建议（§2.4/§5.3）；本副本产出 D 级，主神兑换门槛（基因锁一阶需 D 支线）依赖它 | 新增 `state.sp_grade: Option<Grade>`（D/C/B/A/S 枚举），结算卡展示，`Eff::SetGrade`；主神空间兑换 `cond` 加等级门槛 |
| **战场回合场景效果**（黑发领域 / 仪式镇压） | BOSS 狂暴全场 debuff + 终结技阶段「每回合 BOSS 上限 -8%」为战斗系统新能力 | 建议在 FightCfg 增加可选字段 `aura: Option<{ per_round_san: i32 }>` 与 `finisher_stage: Vec<{ at_hp_ratio: f32, eff: Eff }>`；纯数据驱动，不打散现有战斗循环 |
| **扣点复活结算** | 失败→死亡档案→回主神空间扣 400 点复活（点数不足记负点） | 在主神空间结算端（scenes.rs 结算路由）实现「复活确认场景」，读取 `deaths` 最新一条 → 扣 `points`（可负）→ SAN 回 60 → 装备半损随机剔除；负点在下副本结算先抵债 |
| **天亮时间线**（存活至 6:00 的判定） | 需要「回合/调查推进时间」或简化处理 | 最小方案：不做实时钟，用剧情 flag 推进——探索关键调查点即推进一个阶段（雨夜→深夜→凌晨 3 点→天亮），凌晨 3 点后全层触发一次低语演出；天亮由「真相达成 + 逃离地下室」触发，避免引擎引入计时器 |
| **单人队友系统** | 本副本默认 2 名队友（资深者 + 新人），结算 ×100/人 | 复用现有队友存活计数与 `KillTeam`，无新增 |
| **hauu 演出（灵异事件点）** | 各 PointDef 需要程度化演出（闪屏/变色/震动） | 复用餐厅的 `OverlayDef` + 前端已有演出插槽；若需要「画面惨绿滤镜抖动」小动效，前端加 1 个 CSS/animation class 即可（无需改 Rust） |
| **美术管线** | 新立绘 3 张（伽椰子/俊雄/可选佣人）需走 生图→抠图→png 管线 | 与蜂巢管线一致；伽椰子爬行姿态需 prompt 明确「四肢着地、头颈反折、和服、黑发覆面」，抠图用纯黑背景 |
