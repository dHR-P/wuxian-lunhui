# 副本设计：机关城核心（《侠行天下》）

> 设计人：副本设计子代理（模型 `tokenrhythm/deepseek-v4-flash-0731`，与主线同模型）
> 引擎版本对齐：Rust 引擎现有 SceneDef/EnemyDef/ZoneDef/PortalDef/GateDef/FightCfg 数据模型（见 00_ENGINE_CONTEXT.md）
> 本文件只描述「做什么」，不写 Rust 代码；所有数值/结构按现有数据模型可落地。

---

## 0. 一句话概述（主题/一句话钩子/目标）

- **主题**：青铜/墨色、冷峻精密与腐朽残破并存的机关秘城——墨门湮灭百年后重新运转的机关巨构。本副本的核心差异玩法是**机关解谜门禁链**与**单向传送闭环**：用 GateDef 软锁（道具/flag 解锁捷径）逼你绕险路、用 PortalDef 物理单向门让你"进去了就回不来"，再用回跳秘道把地图缝合成一个可反复探索的箱庭闭环。
- **一句话钩子**：「齿轮为经、机关为纬——这座消失百年的机关城，正在为一个不该被启动的枢机缓缓苏醒。」
- **目标**：从城门潜入 → 破解齿轮阵 → 穿越枢机回廊 → 直取核心控制室；拿到封存的**上古武学图谱残页**与**跨界密匣**（或按守城人遗志封存密匣），满载返回主神空间，冲击最高结算评级。

---

## 1. 设定依据（源自原作哪个具体情节/场景，注明出处状态）

- 本副本改编自《侠行天下》（zhttty，约 2008–2009 起点连载，**中途断更未完结**——书评区共识，框架高置信）的**「候选 1：机关城核心」**场景（见 `xiaxing_tianxia/00_xiaxing_tianxia_research.md` 第五节）。
- 代表性情节（**推断校准**，research 原文）：「江湖传说中早已湮灭的'机关城'现世，传言城内封存上古武学图谱与跨界密匣；各方势力闻讯搜山，主角潜入城门—齿轮厂区—枢机深渊，破解齿轮机关、躲避/迎战机关傀儡，直取核心控制室。」
- 原作风骨参照（模型训练知识，**推断**）：zhttty 武侠作品强调"世界之上还有世界"的悬念底色；《侠行天下》名义武侠、暗藏跨界/天地之力上层真相（research 第二节 3、第五节候选 1 均标「推断」）——机关城内"跨界密匣"即为此上层真相的落点钩子，本副本据此把「密匣之择」做成结局三分支，不做坐实。
- **部分设定未联网核实**：本会话 web_search 连续失败（API 认证错误），无在线来源链接可引；上述"具体广告情节/门派/功法名"一律按研究文档的「推断」规则以通用描述词（墨门/机关傀儡/内功/剑意）替代，不强行使用可能不确证的原著专名。实现阶段如需，可线下补查起点页/百度百科再坐实。

## 2. 主题与氛围（美术色调/音效关键词/情绪曲线）

- **美术色调**：主色 **青铜锈绿 + 墨黑**，辅以 **铜锈橙/烛火橘** 点缀；高对比处用机关**火花白**。城区：浓雾灰绿、断碑青苔；工坊：齿轮阵列深黑剪影 + 底光橙；回廊：高穹顶冷光绿锈；核心密室：墨玉核心幽蓝/暗金脉纹（与蜂巢的医院青绿/血污红做明确差异）。
- **音效关键词**：齿轮咔哒、机括弹响、气闸喷鸣、低鸣轰鸣（地底巨物）、火花噼啪、枯木吱呀、铁索拖地、机关合拢巨响。
- **情绪曲线**：神秘（城门浓雾与断碑）→ 解密紧张（齿轮阵三启与时限暗示）→ 陷阱压迫（弩阵/吊锤/落石）→ 突破枢机的畅快（巨像战 → 密匣之择的余韵）。全程保持"机械不知疲倦、人声稀少"的孤寂压迫感，与蜂巢的尸潮近身恐怖错开。

## 3. 地图结构

- 楼层数：**4 层**（引擎支持 2-4 层，本副本取上限）。
  - L1 城门与外围（外城广场/内城门楼/深巷）
  - L2 齿轮工坊（主齿轮组/天桥/地沟/吊锤井）
  - L3 枢机回廊（桥门楼/中央桥院/侧廊）
  - L4 核心密室（中殿·BOSS 台/静室·隐藏区/密匣石台）
- 尺寸：每层固定 **40 宽 × 26 高**（`#`墙 `.`地板 `P`出生点 `I`装饰/调查点），与引擎 `MAP_W=40, MAP_H=26` 一致。ASCII 为示意底图，**一切判定以坐标表为准**。

- **fight id**：`jc_colossus`；位置：L4 (20,4)（ZoneDef kind=fight BOSS，进入即战）。

## 10. 实现风险与建议

**本副本最新系统（相对蜂巢的新玩法密度高，但全部落在现有数据模型上，不新增引擎能力）：**
1. 机关解谜门禁链：GateDef（道具/flag 解锁捷径）×3 连 + 绕行路线；
2. 单向传送闭环：PortalDef 物理单向门 ×4 + 一道回跳秘道缝合箱庭；
3. 三启 flag 拼合：3 个调查点 SetFlag → 结算处统一判定 `gear_puzzle_clear`；
4. 结局三分支：`jc_box_choice` 由 open/seal/destroy 三 flag 归一；
5. AddItem 作门禁与终结技材料（`it_gear_key`/`it_pivot_key`/`it_gear_token`×3）。

**最小改动建议（按风险从低到高）：**
1. **三启拼合零改**：三个 PointDef 各 SetFlag，`compute_settlement`/`GateDef` 处按三 flag 齐全判定即可；无需新系统。
2. **G2/G3 的单一解锁条件**已符合现 GateDef（一个 need_item 或 need_flag）；如需求"道具+flag 双条件"，建议拆两扇叠置门（两扇 GateDef 同格），引擎零改。
3. **枢机令×3 计数**：若现 AddItem 不支持同 id 计数，直接把三枚拆为 `it_gear_token1/2/3` 三个独立 id（finisher 条件=三 id 齐备），改动最小。
4. **环境伤害点**（落石/吊锤/碾压阵）：落地为 PointDef 文本 + `Hurt(-5/-8)`（引擎已有 Eff），零新系统。
5. **撤离阵**：胜利后经结局幕路由回主神空间即可；若 PortalDef 需解锁条件，加一个前置 flag（胜利 flag）或直接省略撤离阵、全走剧情路由。
6. **数值校准**：巨像 HP160 以 3 人小队每回合约 35-45 输出估算为 4-5 回合战；狂暴后若 2 回合内无法终结（无枢机令时），建议把 HP 降 10-15 或放宽狂暴阈值到 HP60；隐藏 BOSS 同理微调。另注意 `jc_colossus` 奖励 550 与蜂巢 licker 500 同量级、机关城主线总奖励略高约 18%（符合 10-20% 目标）。
7. **新美术量**：6 张新立绘 + 5 张背景，建议主 agent 分批生图（BOSS 立绘优先），设计子代理提供视觉描述与配色已在上节备齐。
