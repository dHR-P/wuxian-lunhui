### 1.3 引擎上下文要点(ENGINE_CONTEXT 全文摘要)

- **形态**:Windows 桌面游戏(Tauri v2 + Rust 引擎 + Web 前端),2D 俯视网格箱庭(40×26×N 层)+ 文字剧情选择 + 回合制指令战斗 + 主神空间结算循环;存档 `data/save.json`。
- **剧情 DSL**:`SceneDef`(bg/loc/mood/speaker/voice/text/choices/fight_id)、`ChoiceDef`(label/sub/cond/effects/route)、`Eff::SetFlag|San|Points|PointsIfFlag|Hurt|Weapon|AddItem|MarkPoint|KillTeam`、`OverlayDef`。
- **状态**:`points`(奖励点数)、`san`(理智 0-100)、`hp`、`weapon`、`ammo`、`flags`、`inventory`、队友存活、`map_objs`、死亡档案 `deaths`。
- **开放世界(maps.rs)**:`PointDef` 调查点 / `EnemyDef` 巡逻敌方 / `NpcDef` 对话 / `ZoneDef` 特殊区域(puzzle/fight)/ `PortalDef` 传送门(**物理单向**)/ `GateDef` 门禁软锁(need_item/need_flag),每世界固定 40×26、层数可变(现 4 层)。
- **战斗(scenes.rs FIGHTS 表,9 套)**:`zombie1_save/far(34) b_chef(38) b_guard(36) mut_guard(42) horde(55) licker_larva(60) licker(112/奖500) hunter_elite(92/奖120)`;FightCfg 字段 name/hp/dmg/reward/rage_at/on_rage/finisher/win/death。
- **结算(唯一权威 `compute_settlement`)**:`total = points + 存活队友×100 + 支线flag数×200`;评级 S≥1600 / A≥1300 / B≥1000 / C≥700 / D。
- **主神空间雏形**(s_nexus):半圆形广场 + 张杰 NPC + 兑换目录(细胞活力强化 800 / 基因锁第一阶段 2000+D / 初级吸血鬼血统 3000+C);Z 宇宙目标 = 扩展为主箱庭(广场/兑换/复活/评价/多任务世界传送门),《生化·蜂巢》保留为第一个小副本。
- **硬约束**:设计文档不写 Rust 代码,数值/结构必须可落地;参考社区来源须标注链接。

## 四、按作品详述

### 4.1 《大宇宙时代》(dayuzhou_shidai)

近未来地球被中子星碎片逼近,人类乘「希望号」方舟逃离,在贫瘠宇宙中沿文明等级阶梯求生;灾难随机催生宇宙适应者(NT)。「希望号生存+文明进化」的星际生存基调,是主神空间高科幻任务集群的底色(研究文档标注:末日细节/生命守恒定律等有「推断」项)。

- **沙丘魔海·坠毁之星**(`shaqiu_mohai.md`):首跃迁后登陆沙漠行星,绿潮共生体吞没一切——4 层「残骸→绿潮战场→共生体母巢→深渊洞穴」垂直结构,与蜂巢的封闭工业风形成「开阔异星+活体植物」反差。核心亮点是**全程氧气倒计时**(侦察/探索/绕行都是资源决策)、「狰狞之绿」母巢的活体墙体与孢子毒气区、以及「伪装文明的智慧生物」欺骗对话轮(感应者读出对方「在馋水分」)。BOSS 渴水兽王(HP240)狂暴后从汲取池再生,弱火弱电克制 +「诱水剂」触发脱水终结技,把「感应者的读心」变成可玩机制;胜利可带「遗泽种子」回主神解锁二级文明高斯武器线。
- **远古遗迹·遗泽**(`yiji_yize.md`):「神迹与盗墓的二元恐惧」——疑似 8-9 级文明遗迹,全部敌人为自律兵器/能量态(无生物敌人),机关与门禁链是主轴:扫描陷阱、矩阵顺序谜题、引擎三步断电、四护盾碎片解锁顺序。BOSS 遗迹仲裁者(HP180)带**四维护罩伤害系数(0.4→1.0)**,护盾阶段变成「回合间读图解谜」;结尾「带走遗泽/留下警示/贪婪强夺」三选一点名为本副本最大特色,影响主神兑换线(三级能量武器线 vs 空间技术彩蛋线)。副本文档自称是「机关/门禁/阶段 BOSS」原型,组件可复制到后续副本。

### 4.2 《洪荒历》(honghuang_li)

把洪荒重构为万族压迫人族的黑暗史诗,人类靠智慧团结与基因锁自救的「至暗时刻」;位阶体系与《无限恐怖》同源(郑吒=盘古)。两个选定副本定位为 **Z 宇宙第 2、3 号任务副本**,数值基线为蜂巢的 1.2~1.5 倍,剧情核心是「人族小人物情感线」。

- **银色大地·地灵族机界遗迹**(`yinse_dadi.md`):洪荒版「切尔诺贝利」——y+E 年地灵族「机界升华」被东天二皇镇压、瓦罗战死造就白银色死亡战场。4 层「战场→都市遗迹→升华工厂→瓦罗之墓」,首次引入**顺序机关链**(三配电点 master→B→C)与**两段式 BOSS**(瓦罗残响 380+300,升华降临可打断),并确立「圣位只做残响/演出不进 fight 数值」的设计铁律(东天二皇投影/龙族高圣尸骸均为演出级)。真相回放揭示「瓦罗被鲲鹏算计」的冤屈,结局有复仇/和平归还/私藏碎片三向分支;产出力量之道·古之残响、心灵之光·稚芽等兑换。

无限流开山之作,本项目的框架本尊:主神空间 + 恐怖片任务世界 + 点数/支线双货币兑换;现有《生化·蜂巢》是它的第一章复刻,本作三个副本按「生化→咒怨→异形→摩瑞亚」引导曲线排布。

### 4.7 《侠行天下》(xiaxing_tianxia)

传统武侠行侠记,武道极境之上藏着「天地之力/异界」上层真相(推断);原作断更未完结,改编以中前期可考场景为本。两副本一个机关解谜、一个心境对决,玩法差异最大、素材复用度高,研究文档明确二者可**零新引擎系统**承载。

- **机关城核心**(`jiguancheng.md`):墨门湮灭百年后重新运转的机关巨构——4 层「城门→齿轮工坊→枢机回廊→核心密室」,核心差异玩法是**机关解谜门禁链**(G1 钥→G2 齿轮阵三启→G3 枢机钥,越深入越依赖机关知识)+ **单向传送闭环**(4 道单向门 + 1 条回跳秘道缝合可反复探索的箱庭;「进去了就回不来」的压力设计)。BOSS 枢机巨像(HP160)狂暴「齿轮碾阵」全场判定,集齐 3 枚枢机令「以令夺枢」终结;隐藏 BOSS 入魔的守城人(HP140)可出示完整墨令免战解脱。结局密匣三分支(开启/封存/毁匣)接「星图之外另有星图」的 Z 宇宙彩蛋钩子。文档自我评估:**零新增引擎能力**。
- **剑冢禁地**(`jianzhong.md`):名门大派千年禁地——历代剑客埋剑于此、剑气千年不散。4 层「山门古道→埋剑长廊→剑冢深谷→无名剑碑」,越深入剑意压身(san 渐降)、心魔显影;**心魔镜像战克制玩家当前武器**、静心打坐等恢复点与低 san 强制事件构成「心境管理」循环。BOSS 剑冢之灵(HP150)是引擎首个**战斗内读取玩家 san** 的设计(低 san 获心魔加持、高 san 反弱并可触发「问心一剑」终结技),与蜂巢战斗节奏完全相反;结局拔剑(得无名剑 Weapon 18-24)/不拔剑(剑灵释然消散)双结局,结算文案引导「为谁而挥」的一问一答。产出兑换:无名剑诀(1500+D)、静心诀(350)等。
