# 副本设计：死亡开端·大裂隙（《死亡开端》zhttty）

> **模型声明**：本文档由副本设计子代理撰写，使用模型 `tokenrhythm/deepseek-v4-flash-0731`（与主线同模型）。
> **工作过程备注（降级说明）**：本副本 4 层地图**全部给出严格 40 宽 × 26 高 ASCII 图**（非区域表替代）；
> ASCII 与全部对象坐标均经 PowerShell 脚本校验（每层 26 行 × 40 列、字符集仅 `# . P I`、全部对象坐标落在可行格上），**无降级**。
> 设计依据引用 `00_siwang_kaiduan_research.md` 的可信度标注：框架性内容（死亡之源=大裂隙、旧神遗骸、越深死者越活跃、城镇教会抵抗）直接使用；人名/细节类一律以通用描述词设计。
> 本副本所有数值相对《生化·蜂巢》口径（ENGINE_CONTEXT §2.3）上浮 20–30%，属高级副本（对标研究文档 §六.4）。

---

## 0. 一句话概述

- **主题**：旧神遗迹 / 源头终局副本——深入荒原尽头逐层撕裂的大裂隙：荒原边缘 → 裂隙矿道/墓穴 → 亡者之城 → 源头祭坛，共 4 层；越深入「死者复苏越快、理智（san）压力越大」，营造终局压迫感。
- **一句话钩子**：「所有死者都在朝同一个方向走——你也是时候去看看了。」
- **目标**：抵达裂隙最底层的源头祭坛，击败终局 BOSS「开端·死亡化身」，把「死亡开端」的真相（或至少一块碎片、一句话、一个名字）带回主神空间。
- **隐藏线（不计入主线结算，仅影响评价文案与额外奖励）**：解开「死亡开端的真相 = 旧神之战残留」的裂隙铭文 → flag `rift_truth`。

## 1. 设定依据

以下按《00_siwang_kaiduan_research.md》可信度分层引用：

| 采用内容 | 置信度 | 本副本用法 |
|---|---|---|
| 世界被「死亡」力量侵蚀，死者复苏为亡灵仆役，活人被触碰即成傀儡 | 框架高置信 | 4 层从表及里的死亡浓度递增，越深复苏越快（L4 复苏死潮增员机制） |
| 蔓延源头是一处大裂隙/古陵/旧神陨落之地，教会封印并讳莫如深 | 框架高置信（命名+结局导向） | 副本即「深入被封印的大裂隙」；入口处设「裂隙封印碑」交代教会史 |
| 圣光能压制死灵浊气，圣职者是精神支柱兼武力核心 | 框架高置信 | L3 教堂「黎明圣所」提供圣物（对亡灵特攻兑换凭证）；L2 磷火灯塔=人类褪魔手段 |
| 死亡之源为旧神遗骸或失败仪式的产物 | 推断 | 终局 BOSS「开端·死亡化身」=旧神遗骸复苏的具象化身（设计为「神已死、死却活着」） |
| 教会信仰的神与死亡背后的旧神之间的真假之辨 | 推断 | 隐藏揭示线 `rift_truth`：源头铭文记载旧神之战——「死亡」是旧神倒下时摔碎在世界上的残响 |
| 具体人名/具体情节节点 | 低 | 一律不用原著无法确证的术语，全部使用通用描述词（守墓人/老钟匠/圣物/低语者） |

> 设计补充原则：副本不引入小说中无法确证的专名（如具体主角名、招式名），保证可自洽落地；世界观缝合彩蛋（与《无限恐怖/无限曙光》联动）仅存在于隐藏揭示文本中，不影响主线。

## 2. 主题与氛围

- **美术色调**：漆黑裂隙主体 + 磷火幽蓝（L2 起主光源）+ 白骨与霜白龟裂（地面装饰纹样）+ 旧神残响的深紫/墨绿高光；L1 地表为灰蓝荒原、渐入漆黑。
- **音效关键词**：持续低语（背景层）、远处钟声（L3）、骨头摩擦/碎裂声、旧神的低频残响（L4）、耳鸣拟声（san 侵蚀时触发）。
- **情绪曲线**：开场（荒原作序的孤寂）→ L2（纵深下坠的压抑，san 首扣）→ L3（假秩序死亡的恐怖，钟声事件顶峰）→ L4（终局的肃穆与压迫，boss 战三阶段推动感）。整体为持续下行的「呼吸式」压力曲线：探索-喘息-再下潜。
- **幻觉文本**：san≤40 时部分调查点/对话出现幻觉版本（镜面倒字、重复词、旧神低语），san≤20 时幻觉文本替换为必现。

### 6.5 san 压力实现方案（用现有 San(i32) 效果落地）

1. **逐层强制扣减**：在每层入口（L2/L3/L4）的落点处挂一个强制 SceneDef（P2a 落点 / P3 落点 / 终局层入口），效果 `San(-8) / San(-10) / San(-12)`——与传送门到达事件绑定，不经过选项（或做成「避不开」的单个选项）。
2. **幻觉文本条件**：现有 `cond: fn(&GameState)->bool` 可直接写 `cond: |s| s.san <= 40`（若 state.rs 未暴露 san 字段，见 §10 最小改动建议）；san≤40 的幻觉版文本用不同 id 的 SceneDef 分支挂在同一调查点。
3. **战斗内侵蚀**：狂暴语义在战斗结束结算后挂载后续 SceneDef `San(-2)` 等（§4.1 已给 on_rage 文本与挂载方式）。
4. **san 归零规则（建议引擎新增）**：san 降至 0 → 触发「精神崩坏」结局分支（死亡档案 title「疯狂之死」，cause「san 归零」），同样走 §8.3 扣点复活逻辑——这是本副本压力系统的兜底闸门。

## 8. 与主神空间衔接

### 8.1 入口传送门规则

- 主神空间主箱庭新增「死亡开端·大裂隙」世界传送门（难度标记：高级/推荐通关蜂巢后）。
- **前置条件**（二选一满足即开放）：
  1. 已通关《生化·蜂巢》副本 1 次（有通关记录 flag `hive_cleared`）；
  2. 或玩家累计总强化点数 ≥ 1000（细胞活力/血统/武器投入之和，保证基础强度）。
- 进入投放：L1 荒原边缘 `P` 出生点 (19,2)；入场即挂强制开场幕（§6.2）。
- 副本内**中途退出**：仅可通过回程门 R1/R2/R3 退回上层，但副本「未完成通关」则无法直接结算——若玩家经回程门回到 L1 入口逆传送门（回主神空间），按**已探索进度结算**（未打 BOSS 时评级上限 C，支线照常计入）。

### 8.2 退出条件

- 通关退出：击败「开端·死亡化身」→ 结算卡（自动回主神空间）。
- 提前退出：L1 入口逆传送门，按当前进度结算（上限 C）。
- 完整通关后主神空间对应传送门进入「已通关」状态（可重复挑战刷支线/碎片，奖励减半，见下）。

### 8.3 失败惩罚（死亡 → 扣点复活）

- 任何死亡（含 san 归零「精神崩坏」）→ 死亡档案记录（title/cause 自动生成）→ 自动回主神空间，**扣 800 点复活**（高级副本复活费取蜂巢基准上浮；点数不足 800 则允许负分，记为「债务」，后续副本结算先抵扣债务）。
- 同一副本重复挑战死亡：复活费累计 +200/次（上不封顶），鼓励及时撤退。

### 8.4 对主神空间兑换项的影响（提案 2 个新兑换 + 1 个联动）

1. **死亡系血统「死语者」**：2500 点 + C 支线 + 道具「死亡之种」——死亡系特攻：对亡灵系敌人伤害 +30%，每场战斗开场 30% 概率「号令」1 名敌方转为友方（1 回合），代价：san 上限 -10（高风险高回报，对应研究文档 §六.2「死亡系血统 2500 点 + C 支线」）。
2. **旧神知识卷轴**：800 点 + 道具「旧神碎片×3」——获得「洞察裂隙」：副本中幻觉文本可选阅读（+真相线索）；代价 san 上限 -20（对应研究文档 §六.2「旧神知识卷轴 800 点」）。

### 10.1 本副本最新系统清单

| 系统 | 现状（蜂巢） | 本副本引入 | 引擎改动等级 |

| 幻觉文本条件分支 | cond fn 已支持 | san≤40/san≤20 的双档幻觉文本 | 极小（仅需暴露 san 到 cond 闭包，见下） |
| 死者复苏量递增 | horde 狂暴增援 | L4 复苏死潮「狂暴/战后增员」且按层递增强度 | 中（FIGHTS 建议支持 `min_wave`（增援次数上限）字段；或用固定「增援 fight」近似实现） |

### 10.2 对引擎的最小改动建议（按优先级）

1. **暴露 san 至 cond 闭包**：`defs.rs` 的 `cond: fn(&GameState)->bool` 目前依赖 state 字段可见性——确认 `state.rs` 中 `san` 为 pub 或补一个 `fn san(&self) -> i32` 即可（一行改动），幻觉文本全部走 cond。
2. **FIGHTS 增员上限**：horde 类战斗建议加可选字段 `min_wave: Option<u8>`（狂暴后可增援的最大波数）；若不想改表结构，可用「固定的第二波 fight 对象」（fiss_horde_wave2）近似——本设计两种实现都能落地。
3. **BOSS 多阶段断点**：以「同一 fight 内多个 rage_at 断点 + 形态文本数组」实现（如 `rages: [(360, "phase2 text"), (170, "phase3 text")]`，兼容现有 rage_at 单断点）；或退化为「boss_rift_death / _p2 / _p3 三个 fight 依序手感切换」（血量延续需状态桥接，改动更大，不推荐第一步做）。
4. **san 消耗品路由**：如需「磷火灯油」可用，建议在物品使用处加一个 `use_item_effect` 映射（San(+10)），或先做成「调查点/对话触发」的消耗（不新增系统）。
5. **负分债务**：死亡扣点复活允许 points<0 且记录 `debt` 标记；结算时先抵扣债务——一行状态逻辑，建议与蜂巢死亡逻辑合并实现。

### 10.3 平衡与体验风险提示

- **BOSS 阶段切换节奏**：520 HP 对高级副本合理，但以蜂巢现有武器/强化成长，建议上线前在「已通关蜂巢 1 次 + 至少 1 项强化」的基线存档上试跑一次，若血量偏高压到 460–520 区间可现场调。
- **钟楼事件（city_bell）风险**：全层刷新敌人会显著拔高难度，建议刷新点固定（文档已给固定刷新位），避免随机刷在玩家出生点附近。
- **回程门 R3 条件**：建议「接近祭坛核心后」才激活（flag `altar_scope`），防止玩家过早从 L4 逃出导致 BOSS 战前资源漏斗失衡。
