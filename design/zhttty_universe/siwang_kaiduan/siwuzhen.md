## 0. 一句话概述

- **主题**：末日城镇生存——死雾压城、尸潮围镇，玩家助守军在黎明前守住钟楼；镇内多区域探索（街道民宅 / 市场诊所 / 钟楼教堂），教会与民兵派系互疑、感染排查与内部叛徒支线交织。
- **一句话钩子**：**"钟楼的钟，必须在黎明前敲响——否则整座镇都会变成它们的巢穴。"**
- **目标**：① 击退三波尸潮（守城）；② 找出并处置出卖圣水的叛徒；③ 取回钟锤、爬上钟楼、在黎明前敲响大钟；④ 击败随之破门而入的尸潮领主「雾潮之喉」。可选：凭圣徽开启地下墓穴，挑战隐藏 BOSS 堕落主教。
- **难度标记（主神空间传送门）**：2/5 星，体量与《生化·蜂巢》相当，推荐蜂巢通关后挑战。
- **时限（叙事时钟）**：子夜入镇 → 丑时第一波 → 寅时第二波 → 卯时黎明潮 → 黎明终结。见 §3 与 §6（可用纯 flag 链实现；真实倒计时为可选改动，见 §10）。

## 1. 设定依据（源自原作 + 可信度标注）

- 作品：《死亡开端》（起点中文网，约 2008–2009，zhttty）。本会话无法联网获取资料（web_search 认证失败，研究文档 `00_siwang_kaiduan_research.md` 已如实记录），**以下均依据该研究文档的框架性高置信条目与「推断」条目展开，无在线链接可引**；实现阶段如需可线下补查百度百科 / 起点书页。
- **框架性内容（按原著使用，高置信）**：死亡以"活着的蔓延力量"侵蚀世界，死者复苏为亡灵仆役，活人被"死亡"触碰即成傀儡（研究文档·核心设定 1）；人类以城镇据点、城墙、钟楼、篝火与巡逻队苟活，教会是精神支柱兼武力核心（核心设定 2）；蔓延的死亡有其"源头"，教会封印并讳莫如深（核心设定 3）。
- **推断性内容（按"自洽发挥"处理）**：具体人名、力量名、情节节点均不可考证。本副本以"身份原型"替代原著不确定术语——民兵首领（务实世俗抵抗）、圣女/首席圣职者（教会理想）、屠夫内奸（推断常见张力：资源与信任的撕裂）、大主教（守密人，立场暧昧，仅作彩蛋提及）。力量体系按研究文档第三节：圣光/圣职系、死亡系（主角异类）、武装残存（民兵枪弩）、旧神禁忌知识（san 来源）。
- **改编落点**：采用研究文档第五节「候选 1：死雾镇」的完整建议（死雾压城、尸潮围镇、守钟楼、3 层城镇结构、BOSS「尸潮领主」+ 隐藏 BOSS「堕落主教」），并落实其第六节的入口/复活/兑换联动方案。

## 2. 主题与氛围

- **美术色调**：灰雾（雾街层：蓝灰 #4A5660 基调）→ 锈红烛火（墟市层：昏黄 #6B4A2A 与锈红 #7A2E2E）→ 圣所（教堂层：烛黄圣光 #E8C87A 与暗影 #1A1620 对比）→ 黎明（终结战：圣白破雾 #F2E9D8）。BOSS 战背景统一压暗为铆红/黑紫。
- **音效关键词**：昏沉钟声（每 10 秒一记的低频回响）、远处女声圣歌哼唱、灰雾风声、尸群拖行低吼、烛火噼啪、圣水净化高频 chime、终战大钟轰鸣。
- **情绪曲线**：压抑（子夜入镇，镇民低语与忌惮）→ 合作微光（排查与口碑建立，篝火旁柯恩递来热酒）→ 紧绷（尸潮两波、叛徒对质）→ 绝望（钟锤失窃、城内圣水失效的真相）→ 濒临崩溃（黎明潮破门、可选的圣女献身）→ 一线希望（钟鸣驱雾）→ 释放与余痛（黎明结算，悲壮版/光明版两种结局文案）。
- **san（理智）设计**：怨灵系战斗、坦白异类身份、墓穴禁忌知识等事件扣 san；篝火、圣水、圣女交谈等小幅回 san（引擎已有 San(i32)）。

### 10.2 引擎最小改动建议

1. **【建议】战斗内道具菜单**：本副本的 圣水/银弹/口粮包 需要战斗内"使用"槽位。最小改动：战斗 UI 增加一个"道具"按钮，读取 inventory 中带 `usable_in_fight` 标记的道具，结算挂到现有回合指令流上。
2. **【建议】GateDef 多条件**（可选）：g_church 等门若想用 `flag A OR flag B` 语义，现 need_flag 是单条件。折中：由剧情脚本在任一条件达成时 `SetFlag(church_open)` 合成单一 flag，避免改数据结构。
3. **【建议】结算卡增强**（可选）：compute_settlement 结束后展示 副本 slug、支线图标（7 个 flag）、结局文案分支（saint_sacrifice 光明/悲壮两版）——现有 overlay/card 机制可扩展，不改公式本身。
4. **【可选】全局事件时钟**：若希望"黎明倒计时"真实化（超时＝失败），需在 state 增加 int 事件计数 + 阈值判定。**默认推荐纯 flag 方案**，零引擎改动，风险最低。
5. **【配置】平衡注**：若与蜂巢同档卡 S：将三场波次战 reward 各 -20~-30（改为 80/100/150），主线 BOSS 保持 1000；若鼓励全收集则维持现值（最高约 3500）。

### 10.3 主要风险

- 叛徒线分支多（3 选项 × 2 证据前置），建议实现期用状态机/流程表逐幕验证，重点回归"放走叛徒"分支的队友阵亡与结局文案（不会死锁——g_church 与主线不依赖该分支）。
- 隐藏 BOSS 需要圣徽指引，否则大部分玩家错过：已在幕 8 圣女对话与执事台词埋提示（"墓穴封着一位不愿再睡下的主教"）。
- 井道单向传送（层1(36,20)→层2(33,21)）实现时注意只注册单向 PortalDef，反向需从屠宰场正门绕行；玩家在层 2 未开 g_granary 也不受影响（井道落点在屠宰场内部，无需钥匙）。
- 3 层地图规模与蜂巢相当，但 NPC 密度与分支选项翻倍，回归用例建议覆盖"全支线 S 评价"与"速通最低评价"两条路径。
