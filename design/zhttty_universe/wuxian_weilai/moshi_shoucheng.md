# 副本设计：末世死城·人类防线（《无限未来》）

> 产出方：副本设计子代理（模型 tokenrhythm/deepseek-v4-flash-0731）
> 用途：《无限轮回》（Z 宇宙箱庭）第二个任务世界副本「末世死城·人类防线」
> 依据：`00_ENGINE_CONTEXT.md`（数据模型/模板/硬约束）＋ `00_wuxian_weilai_research.md` §4.1
> 来源说明：会话内联网搜索不可用（确定性鉴权故障），本设计基于研究文档＋无限流框架合理推断撰写；凡推断项均已标注「（推断）」。原著名梗与原文细节建议主 agent 后续联网补证（参考位：百度百科「无限未来」词条、百度贴吧「无限未来吧」、起点《无限未来》书评区）。
> 难度标尺：以《生化·蜂巢》为基线，本副本整体数值上浮 25~35%，战斗节奏为多波次消耗战（研究文档 §5.1）。

## 0. 一句话概述

- **主题**：末日黄昏之下，人类以最后的科技防线硬撼异兽潮——不再是恐怖片里的求生，而是「人类自己的主场」上焦灼的守城战（《无限未来》科技侧气质）。
- **一句话钩子**：「兽潮将至，人类的时代只剩下最后四面墙。」
- **玩家定位**：主神空间派入的轮回者，受死城守军司令部委托，协助撑过「第七次兽潮」直到轨道支援清场（智慧体「氢弹洗地」名梗的克制版（推断），正式表达为**轨道支援指令**）。
- **目标**：守住四面城墙 → 深入城内医院/军火库救人与武装 → 突入地下指挥所取得轨道授权 → 登炮台观测台呼叫轨道打击清场、护送幸存者撤离。通关即「绝地清场」；战死则回主神空间扣点复活。

## 1. 设定依据

- 改编自《无限未来》（zhttty，又名《无限恐怖2之无限未来》）中「人类文明科技逆袭」的总基调与「兽潮围攻人类城市基地」气质场景（研究文档 §4.1 选中项）。
- 世界观依据：本作核心命题是「人类不再依赖主神与血统，而是以科技硬撼神秘侧」；面对异兽潮，人类惯用手法是「更大当量」——核武/轨道炮物理超度（推断为本作战斗美学）。本副本取其**克制版**：不会真的让核弹落地，而是以「轨道支援指令」完成绝地清场（研究文档 §2.2「氢弹洗地」名梗）。
- 场景细节（推断，依据研究文档 §4.1 列出的代表性情节风格化展开）：
  1. 「防空警报在城市上空拉响，第七次兽潮的通报从指挥所广播里挤出来：三十七分钟——他们只剩三十七分钟。」（守城压迫感开场）
  2. 「重火力阵地的炮管打红了，民兵在城墙上把最后一箱弹药抬上阵地；有人哑着嗓子喊：『把这一发留给最大的那个家伙。』」（弹尽粮绝的转折）
  3. 「指挥所里，老指挥官把授权码推到轮回者面前：『轨道支援只有一次。要么现在清场，要么留着等那个破墙的巨兽爬上来。』」（抉择分支）
- 以上为「人类防线」阶段的代表气质；具体人名/台词原文以原作为准（推断待补证）。

## 2. 主题与氛围

- **美术色调**：黄昏橙灰主调（落日压城、烟尘弥漫）、火光与曳光弹点缀（城墙火线、燃烧的街垒）、指挥所冷蓝荧光对比；整体比蜂巢（狭小黑暗）更开阔、更「暖而绝望」，形成美术差异化。
- **音效关键词**：兽潮低吼（远→近）、防空警报（三短一长）、炮火轰鸣（重低音）、指挥所电台沙沙声、撤离汽笛。
- **情绪曲线**：焦灼坚守（F1 城墙首波）→ 弹尽粮绝（F2 医院/军火库与 F3 指挥所抉择）→ 绝地清场（F4 观测台轨道支援）→ 幸存曙光（撤离结局）。
- **节奏**：多波次消耗战（每层 2~3 波），穿插补给点与 NPC 对话喘息；FOE 分数感来自「撑住波次、节省火力」。

## 3. 地图结构

- **楼层数**：4 层。层名：F1 城墙与外街 / F2 城内医院与军火库 / F3 地下指挥所 / F4 炮台观测台。
- 每层网格 40 宽 × 26 高（与引擎 `MAP_W=40, MAP_H=26` 一致）。地形字符：`#` 墙、`.` 地板、`P` 入口（出生点）、`I` 装饰/调查位。
- ASCII 为**结构示意图**（示意性字符排布），**精确坐标以各层「区域划分表+关键坐标」为准**（实现时按表落位）。

## 5. BOSS 设计

- **名称**：狂化攻城巨兽（Siege Beast · Rampage）—— fight id `fight_r_siege_beast`
- **HP**：150（建议区间 145–155）；**dmg**：(20,30)。
- **狂暴血量/表现**：
  - phase 1 起始即「破墙者」：开场由 F4 东墙(35,6)破墙登台，场地掩体减少（剧情文本层）。
  - **狂暴 @ HP<100（约 2/3）**：破城+增员——每 3 回合召唤一只兽潮·决死加入战场；城墙塌陷段掩体失效。
  - **阶段二「破城狂暴」@ HP<40**：熔火甲片剥落，dmg 升至 (24,34)，每回合对全队小范围震荡伤害（15–20），增员频率改为每 2 回合。
- **终结技条件**：持 flag `orbital_auth`（F3 指挥官授权）且已调查信标塔(26,6)时，出现选项「呼叫轨道支援」。使用「轨道支援指令」（消耗品/flag）：对 BOSS 造成 **120 点固伤**并清空场上全部增员（一次强效清场，对应「氢弹洗地」克制版）。未获授权则无此终结技，需 8–11 回合纯火力硬磨（BOSS 全程二阶段强度）。
- **胜利掉落与奖励点**：奖励 700 点；掉落 AddItem「巨兽晶核 beast_core」×1（主神空间科技侧兑换抵扣物，见 §8）；触发结局「绝地清场」+ 撤离结算（§6 幕三）。
- **失败去向**：团队全灭 → 死亡档案「战死城墙」→ 结算失败（扣除应得点数）→ **回主神空间扣 500 点复活**（点数不足则挂账，见 §8）；剧情复述「城墙还在——下一波，我们再来」。

### 幕一 · 开场「兽潮将至」（F1 城墙平台，bg=f1_citywall_dusk，mood=焦灼）

  1. 「即刻上城墙协防」→ 效果 Points(+15)、路由 f1_combat_1（首波：fight_f1_pack）→ flag `f1_first_combat`。
  2. 「先奔军需配给站领弹药」→ 效果 AddItem(弹药箱)、Points(+10)、路由 f1_supplies；配给站调查后返回再战。→ flag `ammo_ready`（后续首战 BP 消耗 -1 轮）。

### 幕二 · 关键转折「弹尽粮绝」（F2 医院 / F3 指挥所）

- **F2 医院（bg=f2_hospital）**：军医 NPC「药房和病房都进了东西，敢跟我去拼命吗？」选项：
  - 「随军医救护士」（战斗 fight_f2_mutant，胜利）→ flag `medic_trusted`（解锁医院东门捷径 + 幸存者救援线）。
  - 「先夺军火库要紧」→ 跳过救护士，flag `medic_failed`（医森线永久关闭，评价减值）；直接打 gate_armory 线。
- **F3 指挥所（bg=f3_command）**：老指挥官把授权码推过来：「轨道支援只有一次，留着等破墙的巨兽。」选项：
  - 「重启反应堆，换取授权」（进反应堆机房：需撬棍 crowbar；重启调查点）→ flag `power_restored` + flag `orbital_auth`（主线关键）。

### 幕三 · 结局「绝地清场 → 幸存曙光」（F4 观测甲板，bg=f4_observatory）

- 巨兽破墙登台（BOSS 战引导文本「人类的时代只剩下最后四面墙——现在是第三面。」）。
- BOSS 战胜利后结局选项：
  - （cond: orbital_auth 且调查过信标塔）「呼叫轨道支援」→ 效果 消耗轨道支援、fight 终结技流程（120 固伤清场）→ 结局 `evac_done` + overlay「绝地清场」：火线洗尽，幸存者沿索道撤离，黎明剪影。→ 评级加成、sp_grade C 支线发放。
  - 「让我们的炮口也硬一次」（无授权/自选）→ 惨胜结局 `evac_hard`：城墙半毁、部分幸存者损失（beacon 幸存者 flag 结算减一），战斗自豪 flag `last_stand_honor`。
- 全体复活/撤离结算卡（同蜂巢结算流程，进入主神空间）。

## 10. 实现风险与建议

- **沿用即有系统（零改动）**：4 层 40×26 网格、PortalDef 物理单向、GateDef 软锁、SceneDef/Eff（SetFlag/Points/AddItem/Hurt）、死亡档案、结算支线 flag ×200、主神空间传送门与兑换目录框架。
- **多波次消耗战（最小改动）**：用 ZoneDef(kind=fight) + 战斗链（win → 下一 fight_id）实现「波次表」；增员用引擎已有的增员型 FightCfg（on_rage 补兵参数）表达。风险：战斗链需新增「波次索引」字段（建议 FightCfg 增 `next_on_win` 可选字段，改 1 处枚举/表即可）。
- **轨道支援=解锁性 flag 强效单场（最小改动）**：用 FightCfg 的 finisher 条件（cond: orbital_auth）→ 消耗 flag/道具 → 固伤 120 + 清增员 + win 路由到结局；本质是"条件化终结技"，无需新战斗系统。燃烧手雷 gj_grenade 同理（FightCfg 增可选 `strike_damage` 字段兜底）。
- **幸存者计数（需确认）**：引擎全局状态只有队友存活布尔。建议以 flags 计数（survivor_1/2/3 三段）替代"可变 NPC 数量"，结算用 PointsIfFlag；若后续要真计数，需加一个 int 槽位（最小扩展）。
- **补给平衡**：多波次下 HP/弹药消耗大 → 每层设 1~2 个补给调查点（配给站/弹药升降井），避免死锁；扩散风险：补给过多则消耗战失去意义，数值在 F2/F3 首测调整。
- **地图校验**：4 张 ASCII 严格 40×26，落地时加断言/脚本校验行列数（与蜂巢一致），本设计示意图中个别装饰行的逐字符计数以区域表坐标为准。
- **难度手感**：兽潮群像与 BOSS 上浮 25~35%，若首测过难/过易，优先调 fight 表数值与增员频率，不动结构与剧情。
- **复用最大化**：本副本 4/9 敌人纯改色复用、1 个复用+可改、3 个新立绘（其中掘地兽可降级为改色复用）——美术成本低于蜂巢首发时的定制量。
