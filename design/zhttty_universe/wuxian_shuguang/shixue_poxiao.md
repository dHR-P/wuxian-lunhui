# 副本设计：破晓封锁区（《无限曙光》·杀出破晓卷 / 《嗜血破晓》位面）

> 设计子代理：tokenrhythm/deepseek-v4-flash-0731（与主线同模型）
> 依据：`00_wuxian_shuguang_research.md` 第 5 节「首选二：破晓封锁区」+ `00_ENGINE_CONTEXT.md` 引擎规范。
> 本设计只描述「做什么」，不写 Rust 代码；所有结构/数值可落地到引擎数据模型。

---

## 0. 一句话概述（主题/钩子/目标）

- **一句话概述**：在吸血鬼统治、行将崩溃的末世城市「破晓市」，玩家追随吸血鬼科学家**爱德华·道尔顿**穿越封锁区、潜入地下叛军据点、攀上黎明尖塔，赶在太阳升起前校准「日光镜阵」，让城市重返阳光——同时必须遵守主神任务规则：**找到道尔顿后不可离开其半径，否则抹杀**。
- **一句话钩子**：「太阳升起之前，这座城市会把我们都吃掉。」
- **目标**：在 150 回合（游戏内 03:04→04:58）时限内抵达尖塔顶层，击败高级沉沦者·格里高尔，启动镜阵；超时或脱离护送半径即触发失败/抹杀结局。
- **核心循环**：压抑潜行（L1 街道，学习半径规则）→ 三方博弈（L2 地下，人类叛军/温和血族/中立抉择）→ 黎明决战（L3 尖塔，回合倒计时 + 镜阵终结技）。

## 1. 设定依据（源自原作细节，标注来源/推断）

依据 `00_wuxian_shuguang_research.md` 第 5 节「✅ 首选二：破晓封锁区」，引用如下（**标注来源**）：

- **位面与卷目**：「吸血鬼统治的末世城市濒临崩溃，人类残余与"新人类"（嗜血破晓=人类重返阳光）在黎明前决战；楚浩此卷经历**绝境任务**、**沉沦者**（疯狂吸血鬼）、任务限制规则（百科原文：找到主角爱德华·道尔顿后不可离开其一千米半径，否则抹杀——此任务限制即出自该卷位面[推断按词条位置]）。」卷目佐证：「进入！嗜血破晓！、绝境任务？、沉沦者！、地下！、等待阳光、决战！、恐怖的高级沉沦者与……回归！」【来源：研究文档 §5 首选二；原始出处：百度百科《无限曙光》词条卷目录】
- **任务类型**：「绝境任务」——本副本对标为 **D 级绝境任务**：高奖励 + 硬任务限制（半径跟随）+ 数时时限，在 §8 与主神空间「规则难度」彩蛋挂钩（研究文档 §6.3）。
- **核心敌人**：「沉沦者（疯狂吸血鬼）」「恐怖的高级沉沦者」——本副本 L1 引入沉沦者，L3 BOSS 即高级沉沦者·格里高尔（推断名，词条未给具体名，按"恐怖的高级沉沦者"卷目命名）。
- **结局意象**：「等待阳光」「决战！」——即本设计的「日光倒计时」系统与黎明决战：人类重返阳光 = 结局文本三个变体的共同底色。
- **本副本对原作细节的改编与推断说明**：
  - 「一千米半径」按引擎格距换算为 **10 格**（1 格 ≈ 100m，设计口径），并落地为「分段护送锚点」机制（详见 §10 最小改动方案），保证规则感且不压抑 40×26 整层探索。
  - 电影《嗜血破晓》原有人类角色（叛军首领奥黛丽·班尼特、爆破手埃尔维斯）与「血族贵族埃德加·冯·豪森」（推断命名，对应原作"三方势力"支线空间）作为本副本 NPC 使用；具体对白与支线走向为创作演绎【推断】。
  - 「日光镜阵」为创作装置【推断】：原作中「等待阳光」的解法是让阳光回归城市，本副本将此具象为尖塔顶层的可校准镜阵机关。

## 2. 主题与氛围（美术色调/音效/情绪曲线）

- **配色**：
  - 主色「紫夜」`#2b2340 / #3a2f6b`（永夜都市、尖塔内部冷光）；
  - 辅色「血橙」`#f08c4a / #ff6b35`（霓虹残灯、血站灯箱、黎明地平线）；
  - 人类据点「灰暗求生」`#5a5a5a / #8a8a7a`（地下排水道、油灯暖黄 `#d9a441` 点缀）；
  - 决战时刻反转「金白晨光」`#ffd98a → #fff7e6`（穹顶玻璃外透入的日光）。
- **音效关键词**：喉音低语（沉沦者吟唱）、钟楼报时（03:00/04:00 钟声 = 阶段切换信号）、管道滴水、发电机低鸣、玻璃穹顶风啸、日光射线的尖锐共鸣声。
- **情绪曲线**（三幕式）：
  1. **压抑潜行**（L1）：空旷街道、BGM 稀疏低音，敌弱但规则恐怖（半径警告第一次响起）——紧张源是「规则」而非敌人；
  2. **三方博弈**（L2）：调度感与不安，BGM 加入军鼓与无线电底噪，阵营抉择带来的道德压力；
  3. **黎明决战**（L3）：钟楼报时加速 → 决战前 30 秒鼓点渐强 → 日光射线共振音 → 胜利后万籁俱寂，仅剩晨光与钟声。

## 5. BOSS 设计：高级沉沦者·格里高尔

- **背景（推断创作）**：血族当局以「完美日间战士」为目标、将沉沦者狂暴因子与贵族血脉混合的基因实验产物；实验失控，格里高尔吞噬了尖塔整个实验层，成为黎明之塔的活体噩梦。卷目「恐怖的高级沉沦者与……回归！」即指向它。
- **HP / 伤害**：HP 120，伤害区间 16~24，奖励 380 点（镜阵校准+黎明阶段变体 `boss_gregor_mirror` 为 400 点）。
- **狂暴血量**：HP ≤ 60（半血）触发**嗜血狂化**。
- **狂暴表现**：狂暴文本「血……还给我——！！」；ATK 区间 +5（21~29），且每 3 回合召唤 1 只沉沦者（增员 fight `degenerate`）；背景音切换为双倍喉音低语。
- **终结技条件（日光射线，三前置缺一不可）**：
  1. flag `poxiao_dawn_mirror`（镜阵列 左镜→右镜→主控 三处调查完成）；
  2. 阶段2（回合 ≥110 或 BOSS 狂暴后，镜阵自动充能"已完成"）；
  3. 决战开场 SceneDef 选择「校准主控台」→ flag `poxiao_sunray_ready`。
  - 战斗中：BOSS HP ≤ 40 且 `poxiao_sunray_ready` → 触发终结技演出：穹顶玻璃折射 + 日光射线贯穿（BOSS 受 60 点日光伤害 + 灼烧 2 回合 ATK−50%），随后进入处决窗口。
- **胜利**：+380（或 400）点；掉落 **AddItem 日光结晶** + AddItem 血族贵族的实验档案（带回主神空间解锁说明，见 §8）；触发「决战！……回归！」结算场景。
- **失败去向**：死亡档案「被高级沉沦者撕碎」→ 回主神空间 **扣 300 点复活**，副本重置；若为超时结局（见 §6）则另有死亡档案。
- **取舍建议（血族贵族·埃德加路线）**：埃德加路线**不替换 BOSS**——卷目「恐怖的高级沉沦者」必须是必战高潮，换 Boss 会破坏"绝境任务"的压迫感。埃德加的作用是**决战援助**：内应清退 2 只尖塔卫队（决战前排敌从 2 只减为 0）+ 赠道具「血清注射器」（BOSS 首回合 ATK−30%）。实现上全部走「前置剧情事件 + 道具」而非改 fight 静态值（见 §10 方案 C），引擎零改动。若玩家在 L3 与埃德加敌对（选择背叛），则决战额外 +2 只尖塔卫队参战作为惩罚。

## 10. 实现风险与建议（新系统最小改动方案）

本副本引入三个新系统：**任务半径跟随（绝对任务限制）**、**日光倒计时（回合制黎明）**、**三方势力抉择+可选敌对**。均给出"不重写引擎"的最小落地路径；其余全部复用现引擎（PortalDef/GateDef/PointDef/ZoneDef/FIGHTS/结算）。

### 方案 A · 任务半径跟随（推荐：分段护送锚点）

- **问题**：引擎 NpcDef 无移动/跟随能力；真正的"道尔顿跟着玩家走"需新 NPC 移动系统，改动大。若把半径钉在 L1 教堂，玩家将永远无法下 L2/L3，破坏整副本。
- **最小改动（约 3 处小改）**：
  1. **数据**：`GameState` 增加 `anchor: Option<AnchorState>`（`{ floor, x, y, radius: u8, escape_turns: u8 }`）；新增 Eff 变体 `Eff::SetAnchor(floor,x,y,radius)` 与 `Eff::ClearAnchor()`（SceneDef 剧情里调用，用于"道尔顿在下一停留点等你"的迁移）。
  2. **判定钩子**：复用现有 `EnemyDef.radius` 的曼哈顿距离检测函数——在玩家移动结算处追加：若 `anchor` 存在且距离 > `radius` → `escape_turns += 1` 并触发一次警告 SceneDef（覆盖文字「道尔顿的信号越来越弱……」+ 配音）；回到半径内 → `escape_turns` 清零；`escape_turns ≥ 3` → 直接走死亡 overlay（`d_px_anchor`，复用现有 Hurt/KillTeam 死亡档案机制）。
  3. **剧情迁移表（锚点踩点）**：L1 教堂内锚定 → 血站剧情后重设锚到 地铁口 (33,21)；L2 到达即设 叛军据点 (8,6) → 主管道中段剧情重设 1 次（(19,13)）→ 电梯前清除；L3 电梯落地即设 大堂 (18,4) 上方决战平台主控台 → 决战开场 `ClearAnchor()`（叙事："决战时刻，已无需护送"）。每段半径 **8~10 格**（≈800~1000m 叙事换算，1 格≈100m），足够覆盖该段主区域又不至于形同虚设。
- **工作量评估**：defs.rs 加 2 个 Eff 变体 + state.rs 加 1 个结构 + 移动结算加 ~10 行判定；半天内，不触战斗/地图系统。**NpcDef 真跟随**列为二期（若未来做 NPC 跟随系统再升级锚点=跟随体）。

### 方案 B · 日光倒计时

- **数据**：`GameState.turn_counter: u16`：每次玩家**移动 1 步或战斗 1 回合** +1（统计口径统一写在引擎注释里，防膨胀）；HUD 显示「距黎明 HH:MM」映射表：turn 0→03:04，80→04:00（阶段1），110→04:26（阶段2），150→04:58（死亡线）。
- **阶段触发**：在回合结算处检查阈值常量（80/110/150）：到达即 `SetFlag(poxiao_phase_1 / poxiao_phase_2 / poxiao_daylight)` 并弹一次阶段提示 SceneDef（钟楼报时声场）。
- **敌人状态变化（零引擎改动法）**：采用**预注册 FIGHTS 黎明变体 + 剧情路由选 id**：`vamp_civil_dawn`（ATK−3）、`rebel_fighter_dawn`（ATK+3）、`boss_gregor_mirror`（镜阵束缚）三条目写死在 FIGHTS 表中，战斗入场由现成 Dyn(fn) 路由按 flag 选择——**不新增 FightCfg 字段**。若后续嫌条目多，可给 FightCfg 加可选 `atk_bonus` 一个字段（1 处 struct + 结算处应用，同样最小）。
- **时限失败**：turn ≥150 且 !`poxiao_dawn_mirror` → 强制 `d_px_dawn` 死亡 overlay（复用死亡机制，零新系统）。
- **风险**：回合口径必须唯一（移动+战斗），并在战斗结算处同步累加，避免玩家"挂机刷回合"卡阶段。

### 方案 C · 三方势力抉择 & 叛军可选敌对

- **三方抉择**：纯 SceneDef choices + 互斥 flag（一次选项只置 1 个阵营 flag），引擎零改动；结局文本、决战支援/惩罚全部由 flag 路由（支援差异 = 前置剧情事件 + 道具，如「血清注射器」「额外卫队参战」以 SceneDef 前置小战实现，不改 fight 静态值）。
- **叛军可选敌对**：推荐把叛军巡逻做成 **NpcDef + 谈话选择**（放行/开战，开战 → Scene 直连 fight `rebel_fighter`），零引擎改动且符合"两义势力"；若现引擎敌方是接触即战，请优先用此方案而非调 radius=0 的 hack。
- **风险**：阵营 flag 互斥需在剧情层保证（三选项写死只置其一即为互斥）；结算文本按 flag 走三套，需在结算卡文案处加 3 个分支（现引擎结算为唯一函数，建议分支只做"称号/备注"文本差异，不改分数公式）。

### 汇总 · 改动面

| 系统 | 改动位置 | 改动量 | 是否重写引擎 |
|---|---|---|---|
| 任务半径跟随 | defs(Eff×2)/state(AnchorState)/移动结算(~10行) | 小 | 否 |
| 日光倒计时 | state(turn_counter)/回合结算(阈值+flag)/FIGHTS(3条变体) | 小 | 否 |
| 三方势力/可选敌对 | 纯剧情数据 | 零~极小 | 否 |
