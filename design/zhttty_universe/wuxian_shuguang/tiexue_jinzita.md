## 0. 一句话概述

**主题**：远古猎场/祭典杀戮——南极冰盖下三千米，铁血战士以异形为猎物豢养了千年的祭坛金字塔；轮回者闯入猎场，既是猎物，也是打破祭典的人。
**一句话钩子**：「每一只异形都是被精心准备的猎物，而你，闯进了猎人的祭坛。」
**目标**：深入三层（冰原营地→墓道迷宫→祭坛圣殿），击杀异形皇后，夺取祭坛深处的「死亡神性颗粒」，活着回到主神空间。

---

## 1. 设定依据

引《无限曙光》作品调研报告（`00_wuxian_shuguang_research.md`，第 5 节『✅ 首选一：铁血·地底金字塔』＋ 第 2.1/2.2 节）：

1. **位面出处**：卷目「铁血力量（AVP）」；「铁血战士在南极冰层下金字塔举行成年礼，异形被当成猎物；楚浩一行深入金字塔」——见调研报告第 5 节首选一（代表性情节条目）。
2. **本副本是死亡神性的来源位面**（百科原文引用自调研报告第 2.1 节）：死亡神性 = 郑吒打碎的**七十万余神性颗粒**，「异形大战铁血战士」位面得到；被动『魔法技能提高至最大效果』，兑换价**双 A 级**。（来源：百度百科《楚浩》词条，https://baike.baidu.com/item/楚浩 ；《无限曙光》词条，https://baike.baidu.com/item/无限曙光 ）
3. **卷目佐证**（报告原文摘录）：「地底……地底！」「寄生」「神性，人性与神性……武器！」「决战开端」——对应本副本 L1 冰层营地→L2 寄生巢→L3 神性祭坛→决战的剧情曲线。
4. **敌人数值参照**：FIGHTS 表量级（HP 34~112、奖励 10~500，BOSS 可超，见报告第 8 节）——本副本在报告中标注的『引擎契合度』：「敌人表参考 licker（湿生）、hunter（人形猎杀者）数值改型；新美术需求 = 异形系立绘 2~3 张 + 铁血战士 1 张 + 皇后 1 张」。
5. 未见于词条的细节（铁血成年礼的具体狩猎规则、祭坛机关形制、皇后巢穴内部结构）一律按「推断」标注，以 AVP 电影常见设定补齐（膜内寄生、酸血、热感应隐形、肩炮）。

## 2. 主题与氛围

- **美术色调**：冷蓝 × 锈红。L1 冰原为冷蓝白（冰层、风雪、蓝灰阴影）；L2 墓道为灰石灰墙 + 锈红装饰（铁血图腾壁画、干涸血液、卵膜粘液反光）；L3 祭坛为暗红 + 金色（祭坛光纹、碎裂圣像辉光、皇后巢穴的深红肉壁）。
- **音效关键词**：金属机关声（齿轮绞盘、腕刃出鞘、肩炮充能的「吭—嗡」）、湿粘蠕动声（卵膜破开、尾刺划地、酸液滴蚀）、低频压迫环境音（冰层挤压的咯吱声、地底气流）。
- **情绪曲线**：**潜入的压迫**（L1：风雪、冰层下未知的猎场警告，压低声）→ **受困的绝望**（L2：单向下降、墓道迷宫、卵巢四面楚歌，同伴中招）→ **祭坛决战的宣泄**（L3：皇后现身、铁血盟友/宿敌同台、终结技一锤定音）。
- **叙事基调**：克制、冷峻的猎场恐怖；楚浩系奥术师视角（冷静算计、情报优先），张恒负责在高压中提供嘴硬式吐槽，铁血战士是「有尊严的猎手」而非无脑怪物。

## 5. BOSS 设计

### 5.1 主线 BOSS：异形皇后（b_alien_queen）

| 项 | 数值/设计 |
|---|---|
| HP | 240（可按第一步落地调至 200，见 §10） |
| 伤害区间 | 20~30；每 3 回合尾刺横扫（追加 Hurt 10 判定） |
| 狂暴血量 | HP ≤ 100（约 42%） |
| 狂暴表现 | **破卵增员**：每回合召唤 1 只异形雄蜂入场（增员参照 horde 的 on_rage 增员模板）；若玩家已达成 flag `eggs_smashed`（破坏 ≥3 处卵巢），增员改为每 2 回合 1 只；同时伤害 +6（狂暴期 26~36） |
| 终结技条件（二选一，运行时检测） | ① 完成 flag `predator_alliance`（与铁血结盟）→ 触发「铁血·肩炮助战」：铁血战士从高处肩炮连轰，对皇后造成大额固定伤害并晕眩 1 回合；② 未结盟 → 完成 ZoneDef 机关「祭坛酸液喷口」（puzzle：按序踩两侧石板）→ 皇后甲壳被酸液软化，终结技窗口开启 |
| 终结技表现 | 肩炮：音效「吭—嗡—轰」+ 皇后甲壳碎裂特写；酸液：石板喷口涌酸，皇后嘶鸣失衡 |
| 胜利掉落 | Points +500；AddItem(`death_divinity_shard` 死亡神性颗粒，任务绑定）；flag `queen_defeated`（解锁 G4 回归门） |
| 胜利奖励点 | 500（主线大头；叠加剧情/支线可达约 600~900/副本，见 §7） |
| 失败去向 | 进入死亡档案 overlay「祭坛陨落」→ 回主神空间**扣 300 点复活**（点数不足则扣至 0）；已拾取道具保留（含神性颗粒——关键道具免掉落，见 §8） |

**皇后战流程（三阶段演出）**：
1. 登场：皇后自卵膜破出，尾刺横扫开局（首次攻击必中 Hurt 8）。
2. 中盘：HP 过半后若未清卵巢，增员提速（对应狂暴）。
3. 终结：满足 ①/② 条件后进入斩首窗口；否则皇后每回合增员直到玩家崩溃（高压惩罚长线）。

| 终结技 | 腕刃连斩（触发窗口：将其逼至墙角的 3 连击） |
| 胜利掉落（猎杀线） | Points +300；AddItem(`predator_wristblade_elite` 铁血腕刃·猎场之礼，攻击类道具/兑换素材）；flag `predator_hunted` |
| 结盟达成（结盟线） | 对话中归还 `iron_blade`（L1 冻尸腕刃）→ flag `predator_alliance`；此后皇后战触发肩炮终结技 |
| 失败去向 | 普通死亡惩罚（回主神空间扣 300 点复活） |

> **取舍建议（针对『皇后 vs 铁血 双路线二选一』的提示）**：本设计采用「**皇后为唯一主线 BOSS**、铁血为支线双路线」——理由：①皇后是 AVP 猎场的闭环（猎物最终反噬猎手），情绪顶点明确；②铁血作支线把「结盟/猎杀」的抉择留给玩家，且结盟线直接服务于皇后战终结技，避免两条主线 BOSS 互相稀释资源；③引擎单 BOSS 战流程更稳（ZoneDef fight 链路简单），铁血战复用普通 fight 链路。若后续想升级为「双主线 BOSS」：仅需把 G3 解锁条件改为二选一 flag（击杀皇后 或 击杀铁血），引擎改动为零，可在平衡性迭代后再开放。

  祭坛中央的碎裂圣像泛着幽光——神性颗粒就在其中。而更大的阴影从卵膜深处立起：异形皇后，这座猎场真正的主人，正把产卵管插进祭坛的石缝。

- 失败：overlay（death card）「祭坛陨落：你成了祭典的最终供品」→ 回主神空间扣 300 点复活。

## 8. 与主神空间衔接

- **入口传送门**：主神空间传送门 → L1 出生点 P(1,1)（复用现传送门机制；作为独立任务世界入口，通关后可再入，便于刷支线）。
- **退出条件**：击杀皇后 → flag queen_defeated → G4 回归圣门解锁，T6(34,24) 回主神空间结算（compute_settlement：points + 存活队友×100 + 支线 flag×200；评级 S≥1600 / A≥1300 / B≥1000 / C≥700 / D）。
- **失败惩罚**：死亡 → 死亡档案 overlay → 回主神空间扣 300 点复活（点数不足扣至 0）；关键道具（死亡神性颗粒/腕刃）保留，防止「关键道具随死亡丢失导致永久卡关」。
- **对兑换项影响**：
  - 新增长期兑换位占位：**死亡神性（双 A 级）**——描述沿用百科原文「被动『魔法技能提高至最大效果』」，兑换价占位（建议 40000 点 + 双 A 支线），第一章仅展示不开放（报告 §6：「修真 S+70000 是远期目标，勿在第一章开放」）。
  - 掉落素材可作「兑换折扣凭证」占位：集齐 death_divinity_shard ×3 → 兑换界面显示灰色占位条目（实现为 inventory 计数 + 兑换目录 flag，最小改动）。
  - 提升本副本奖励上限至约 600~900 点/周目（报告 §6 建议 500-800，可略超），支撑后期物价梯度。
  - 主神空间跨副本彩蛋：结算页「位面编号」标注 AVP-██（对比《生化·蜂巢》R-██），暗示同一多元宇宙（盖亚碎片），纯文本零成本。
